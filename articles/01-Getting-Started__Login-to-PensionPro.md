How Do I Login to PensionPro+?

Category: Getting Started Time: 5 minutes Difficulty: ⭐ Beginner

Related Topics:

Understanding the Layout and Navigation
Find and Use Help
What This Does

Gets you logged into the PensionPro+ system securely using Single Sign-On (SSO) authentication. You'll access PensionPro+ through a web browser, just like any website.

Quick Steps
Open your web browser (Chrome, Edge, or Firefox recommended)
Go to https://clients.pensiontech.io
If not already logged in, you'll be redirected to the secure login page
Enter your email address and password on the authentication page
Check your email for the security code
Enter the security code on the verification page
You'll be automatically redirected back to PensionPro+
Dashboard loads - you're in!
Before You Begin

You'll need:

✅ Your registered email address
✅ Your password
✅ Access to your email inbox (for security code verification)
✅ A modern web browser

💡 Tip: If you don't have login credentials, contact your system administrator.

Step-by-Step Instructions
Step 1: Open Your Web Browser
Open one of these recommended browsers:
Google Chrome (recommended)
Microsoft Edge (recommended)
Mozilla Firefox
Safari (Mac users)

💡 Tip: Bookmark the PensionPro+ URL for easy access later!

Step 2: Navigate to PensionPro+

In the address bar, type or paste the PensionPro+ URL:

Production URL: https://clients.pensiontech.io

Press Enter

What Happens Next:

If you're already logged in, you'll go directly to the Dashboard
If not logged in, you'll be automatically redirected to the secure login page
Step 3: Authenticate (If Required)

PensionPro+ uses Single Sign-On (SSO) for secure authentication:

You'll be redirected to a secure authentication page
Enter your email address:
This is your registered email address
Case-sensitive
Enter your password:
Passwords are case-sensitive
Characters appear as dots (•••) for security
Click Submit or Sign In

💡 Tip: Double-check Caps Lock is off if you're having trouble logging in.

Step 4: Enter Security Code

For additional security, you'll need to verify your identity:

After entering your email and password, check your email inbox
You'll receive an email with a security code
Enter the security code on the verification page
Click Verify or Submit

💡 Tip: The security code typically expires after a few minutes. If it expires, you can request a new one.

Step 5: Automatic Redirect to PensionPro+
After successful authentication and security code verification, you're automatically redirected back to PensionPro+
The Dashboard loads

What You'll See:

✅ Dashboard with system overview
✅ Navigation menu (hamburger icon ☰ in top-left)
✅ Your name in the top-right corner
✅ Search bar and action buttons
First Time Login

If this is your first time logging in:

You may be prompted to set up your password or complete additional authentication steps

Follow the on-screen instructions to:

Set a secure password
Configure multi-factor authentication (if required)
Accept terms of service

Password Requirements:

Minimum 8 characters (requirements may vary by organization)
Include uppercase and lowercase letters
Include at least one number
Include at least one special character (!@#$%)

After setup, you'll be automatically redirected to PensionPro+

⚠️ Important: Store your password securely using a password manager.

Staying Logged In

Session Duration:

Your session stays active while you're using the system
After a period of inactivity (typically 15-30 minutes, configured by your organization), you'll be automatically logged out for security
The system performs background checks to keep your session active
You may need to re-authenticate to continue working after extended inactivity

Keep Your Session Active:

Any click or keyboard action keeps your session alive
If you'll be away from your desk, save your work and log out for security
Common Questions

Q: I forgot my password. What do I do? A: On the authentication page, look for a "Forgot Password?" or "Reset Password" link. Follow the prompts to reset your password via email. If this doesn't work, contact your system administrator.

Q: I didn't receive the security code email. What should I do? A: Check these common issues:

Check your spam/junk folder
Wait a few minutes - emails may be delayed
Verify you entered the correct email address
Request a new security code if the current one expired
Contact your system administrator if you still don't receive it

Q: My email address or password isn't working. A: Check these common issues:

Caps Lock is on (passwords are case-sensitive)
Extra spaces before or after your email address
Using an old password (if recently changed)
Account may be locked after multiple failed attempts
Browser cookies or cache may need clearing

If still having trouble, contact your system administrator.

Q: Why am I being redirected to a different page to log in? A: PensionPro+ uses Single Sign-On (SSO) for security. You're redirected to a secure authentication server, then automatically returned to PensionPro+ after login. This is normal and secure.

Q: Can I stay logged in permanently? A: No, for security reasons, sessions expire after a period of inactivity. The exact timeout is configured by your organization. You'll need to re-authenticate after extended inactivity.

Q: Can I use my phone or tablet? A: PensionPro+ is optimized for desktop browsers. Mobile devices may work but aren't officially supported. Use a desktop or laptop computer for the best experience.

Q: Do I need to install anything? A: No! PensionPro+ is a web application. Just use your web browser - no downloads or installations required.

Security Best Practices

✅ DO:

Use a strong, unique password
Log out when finished working
Lock your computer when stepping away
Keep your password confidential

❌ DON'T:

Share your login credentials with others
Write passwords on sticky notes
Leave your computer unlocked and unattended
Use public computers for accessing PensionPro+
Troubleshooting
Issue: "Invalid username or password"

Solutions:

Verify your email address is correct (check with administrator)
Verify password is typed correctly
Check Caps Lock is off
Try resetting your password
Contact administrator if account is locked
Issue: Security code not working

Solutions:

Verify you entered the code correctly (codes are case-sensitive)
Check if the code has expired (request a new one)
Check your email for the most recent security code
Clear your browser cache and try again
Contact administrator if problem persists
Issue: Login screen won't load

Solutions:

Check your internet connection
Try refreshing the page (F5 or Ctrl+R)
Clear your browser cache
Try a different browser
Contact IT support if problem persists
Issue: "Your session has expired"

Solution: This is normal after a period of inactivity. Simply return to the PensionPro+ URL to re-authenticate and continue working. You may be automatically logged back in if your SSO session is still active.

What Happens After Login?

After successfully logging in, you'll see the Dashboard. This is your home base in PensionPro+.
