How Do I Navigate the Member Directory?

Category: Getting Started Time: 5 minutes Difficulty: ⭐ Beginner

Related Topics:

Find a Member
Understanding the Layout
Add a Member
What This Does

Shows you how to browse, search, and filter the Member Directory to find members quickly. The Member Directory is your starting point for viewing and managing member records.

Quick Steps
Click hamburger menu (☰) in the top-left corner
Select Member Directory from the menu
Member Directory opens showing all members
Use search box to filter by name, ID, or SSN
Use filters to narrow by status, employer, etc.
Click a member's name to open their profile
Step-by-Step Instructions
Step 1: Open the Member Directory

Where to Go:

Look for the hamburger icon (☰) in the top-left corner
Click it to open the navigation menu
Click Member Directory
The Member Directory loads

What You'll See:

List of all members in a table
Search box at the top
Filter options
Column headers (Name, ID, Status, etc.)
Pagination controls at the bottom
Step 2: Understanding the Directory View

The Member Directory shows key information in columns:

Common Columns:

Member ID - Unique identifier
Name - Last, First Middle
SSN - Last 4 digits (XXX-XX-1234)
Status - Active, Retired, Terminated, etc.
Employer - Current or last employer
Date of Birth - MM/DD/YYYY
Actions - Quick action icons

💡 Tip: Click any column header to sort by that column. Click again to reverse the sort order.

Step 3: Search for Members

Using the Search Box:

Look for the search box at the top of the directory

Type any of these:

Member's first or last name
Member ID number
Last 4 digits of SSN
Full SSN (if you know it)

Results filter as you type

Clear search to see all members again

Search Tips:

Search works on partial matches
Not case-sensitive
Searches across multiple fields
Use spaces to search multiple words

Examples:

Type smith → Shows all members with "Smith" in their name
Type 12345 → Shows Member ID 12345 or SSN ending in 12345
Type john smith → Shows members with both "John" and "Smith"
Step 4: Filter Members

Using Advanced Search:

To filter members, use the Advanced Search feature:

Look for Advanced Search button above the table

Click Advanced Search

Filter options appear along with a "Search for Filter" search box to locate specific filters

Common filters available:

Most Recent Status Event (Active, Retired, Terminated, etc.)
Member Type (Regular, Vested, etc.)
Date Ranges (Hire Date, Retirement Date)
Other filters based on your system configuration

Select filter options as needed

Table updates to show only matching members

Clear filters to see all members again

💡 Tip: You can combine multiple filters to narrow your search further.

Step 5: Adjust Table Display

Change Rows Per Page:

Look at the bottom of the table
Find "Rows per page" dropdown
Select: 10, 25, 50, or 100
Table updates to show that many members

Navigate Pages:

Use pagination controls at the bottom
Click ◀ Previous or Next ▶
Or click specific page numbers
Shows "Showing 1-25 of 500" (example)
Step 6: Open a Member Record

To view a member's full profile:

Find the member in the directory
Click on the member's name (blue link)
Member profile opens
You'll see all member details and navigation cards

Alternative - Open in New Tab:

Find the member
Hold Ctrl (Windows) or Cmd (Mac)
Click the member's name
Opens in a new browser tab
Original directory stays open

💡 Tip: Opening in a new tab lets you compare multiple members or keep your search results handy.

Advanced Directory Features
Sorting the Table

How to Sort:

Click any column header
Table sorts by that column
Arrow indicates sort direction:
▲ Ascending (A-Z, 0-9, oldest-newest)
▼ Descending (Z-A, 9-0, newest-oldest)
Click again to reverse sort order

Common Sorts:

By Name - Alphabetical order
By ID - Numerical order
By Status - Groups by status type
By Date - Chronological order
Exporting the Directory

Want to export to Excel?

Look for Export or Download button (usually top-right)
Click the button
Select format:
Excel (.xlsx)
CSV (.csv)
PDF
File downloads to your computer

💡 Tip: Filters and search apply to exports! Filter first, then export to get just the members you want.

Quick Actions from Directory

Many directories have action icons in each row:

Common Actions:

👁️ View - Opens member profile
✏️ Edit - Opens edit form
📄 Reports - Generate member report
💼 Documents - View member documents
Common Directory Views
Members by Status

Filter to see specific groups:

Active Members:

Use Advanced Search
Select Active in Most Recent Status Event filter
Shows only active members

Retired Members:

Use Advanced Search
Select Retired in Most Recent Status Event filter
Shows only retired members

Recently Added:

Sort by Created Date column (if available)
Click to sort newest first
Members by Employer

View members from a specific employer:

Use Advanced Search
Locate and use employer-related filters (if available in your system configuration)
Shows only members from that employer
Tips for Efficient Browsing

✅ BEST PRACTICES:

Use search for specific members
Use filters for groups of members
Sort by status to see member types together
Export filtered lists for offline work
Open multiple members in tabs for comparison

💡 TIME SAVERS:

Recent searches may be saved
Browser back button returns to directory
Filters persist during your session
Bookmark the Member Directory for quick access
Common Questions

Q: How many members can I see at once? A: Up to 100 per page. Change the "Rows per page" setting at the bottom of the table.

Q: Why don't I see all members? A: Check if any filters are applied. Clear filters to see all members. You also may not have permission to see certain members.

Q: Can I save my search/filter settings? A: Filters persist during your current session but reset when you log out.

Q: The directory is loading slowly. Why? A: Large datasets can take a moment. Use filters to narrow results and improve performance.

Q: How do I see terminated members? A: Use Advanced Search and select "Terminated" or "Inactive" in the Most Recent Status Event filter.

Q: What does the number badge mean? A: If you see numbers next to Member Directory in the navigation, that's the total count of member records.

Troubleshooting
Issue: Can't find a member I know exists

Solutions:

Clear all filters and search
Check spelling of name
Try searching by Member ID instead
Try searching by last 4 of SSN
Verify you have permission to view that member
Issue: Directory shows no results

Solutions:

Click "Clear Filters" or "Reset"
Clear the search box
Refresh the page (F5)
Verify there are members in the system
Issue: Column I need isn't showing

Solutions:

Look for a "Columns" or "Customize" button
Scroll horizontally (table may be wide)
Maximize your browser window
Contact administrator about available columns
