Getting Started with PensionPro+

Welcome to PensionPro+! This section covers everything you need to know to get started with the system.

📖 Topics in This Section
Login to PensionPro+

Learn how to access the system and log in for the first time. Time: 5 minutes | Difficulty: ⭐ Beginner

Understanding the Layout and Navigation

Get familiar with the PensionPro+ interface and how to navigate between screens. Time: 10 minutes | Difficulty: ⭐ Beginner

Navigate Member Directory

Learn how to use the Member Directory to browse and filter members. Time: 5 minutes | Difficulty: ⭐ Beginner

Find and Use Help

Discover how to access help resources and documentation within the system. Time: 5 minutes | Difficulty: ⭐ Beginner

Access Settings Screens

Learn where system settings are located and how to access them. Time: 5 minutes | Difficulty: ⭐ Beginner

🎯 Recommended Learning Path

New to PensionPro+? Start here:

First: Login to PensionPro+
Next: Understanding the Layout
Then: Navigate Member Directory
