How Do I Understand the PensionPro+ Layout and Navigation?

Category: Getting Started Time: 10 minutes Difficulty: ⭐ Beginner

Related Topics:

Login to PensionPro+
Navigate Member Directory
Find and Use Help
What This Does

Helps you understand where everything is located in PensionPro+ so you can navigate confidently without getting lost. You'll learn about the main sections, menus, and navigation patterns.

Quick Overview

PensionPro+ has a consistent layout across all screens:

Top Navigation Bar - Search, help, and user menu
Navigation Menu - Access via hamburger icon (☰) to reach different sections
Main Content Area - Where you do your work
Breadcrumbs - Shows where you are (in certain sections)
The PensionPro+ Interface
Top Navigation Bar

Located at the very top of every screen:

Left Side:

Hamburger Icon (☰) - Click to open the navigation menu
PensionPro+ Logo - Click to return to Dashboard
Search Bar (🔍) - Search for members, beneficiaries, contacts

Right Side:

Help (?) - Access help documentation
Batch - View batch processing status
Your Name - Profile, settings (admin only), and logout options
Client Selector - Switch between client organizations

💡 Tip: The top navigation bar is always visible, no matter where you are in the system.

Navigation Menu (Hamburger Menu)

Click the hamburger icon (☰) in the top-left to access the main navigation:

Main Sections:

Dashboard - System overview and quick stats
Member Directory - Browse and manage member records
Contributions Center - Upload and manage contributions
Payment Center - Process payroll and payments
Accounting Center - Accounting and financial management
Year End Processing Center - Year-end tasks
3(8)(c) Center - Manage transfers
Dues Processing - Process union dues
Reports - Generate and view reports
Document Center - Manage documents

Create Actions: Located in a separate right-hand panel of the navigation menu:

+ Member - Create a new member record
Scan Document - Scan and upload documents
Generate Report - Access report generation

How It Works:

Click the ☰ icon to open the menu overlay
Click any module to navigate to that section
Click outside the menu or the ☰ icon again to close
Icons help identify each section

💡 Tip: The menu opens as an overlay panel on top of your current work.

Main Content Area

The center of your screen where all your work happens:

Common Elements:

Page Title - Shows what screen you're on
Action Buttons - Usually in the top-right (Add, Edit, Save, etc.)
Tables - Display lists of data
Forms - Input fields for entering information
Tabs - Multiple sections on one page
Breadcrumbs

Shows your current location in certain sections of the system:

Example: Settings > System Parameters > Interest Rates

Where You'll See Breadcrumbs:

Settings pages
Accounting Center (when navigating sub-sections)
Contributions Center (when navigating sub-sections)
Payment Center (when navigating sub-sections)

What Breadcrumbs Tell You:

Your current location within a module
The path you took to get there
Clickable links to navigate back

How to Use:

Click any breadcrumb to go back to that level
Faster than using the back button

💡 Note: Breadcrumbs appear primarily in multi-level sections like Settings and processing centers, not on the Dashboard or main directory pages.

Key Navigation Patterns
Opening a Member Record

Method 1: From Member Directory

Click hamburger menu (☰) in top-left
Select Member Directory
Search or browse for the member
Click the member's name
Member profile opens

Method 2: From Search Bar

Click in the search bar in top navigation
Type member name or ID
Results appear as you type
Select member from results
Member profile opens

Method 3: From Dashboard

Dashboard often shows recent members or quick links
Click a member name
Member profile opens
Opening Multiple Members

Want to work with multiple members at once?

Hold Ctrl (Windows) or Cmd (Mac)
Right-click a member's name
Select "Open in New Tab"
Member opens in a new browser tab
Switch between tabs to view different members

💡 Tip: You won't lose your place when opening multiple members!

Navigating Within a Member Record

When viewing a member, you'll see sections on the left:

Member Navigation Cards:

Personal Information
History
Financial
Contributions
Calculations
Military
TEC/3(8)(C)
Payroll
Documents
Reports
Messages

How to Navigate:

Click any card to view that section
Current section is highlighted
Information loads in the main area
Using the Navigation Menu for Quick Actions

The Navigation Menu (☰ in top-left) provides both navigation and quick actions:

Navigation Modules: Click any module card to go to that section:

Dashboard, Member Directory, Contributions Center, Payment Center, etc.

Create Actions: Located in a separate right-hand panel of the navigation menu:

+ Member - Create a new member record
Scan Document - Scan and upload documents
Generate Report - Access report generation

How to Use:

Click the ☰ icon in top-left
Scroll through module cards
Click any module to navigate there
Or use Create actions from the right-hand panel
Finding Your Way Around
I'm Lost - How Do I Get Back?

Option 1: Use Breadcrumbs

Click any breadcrumb at the top
Jumps back to that location

Option 2: Click the Logo

Click PensionPro+ logo in top-left
Returns to Dashboard

Option 3: Use Navigation Menu

Click the hamburger menu (☰)
Select the module you want to go to

Option 4: Close Current Tab

If opened in new tab, just close it
Original tab is still there

Understanding Member Profile Layout

When you open a member, here's what you see:

Member Banner (Top)

Always visible at the top of the member profile:

Member Photo (if available)
Member ID and Name
Current Status (Active, Retired, etc.)
Key Dates (DOB, Hire Date, Retirement Date)
Quick Stats (Years of Service, etc.)
Left Navigation Cards

Organized sections of member information:

Click to view that section
Current section highlighted in blue
Number badges show items (e.g., "3 Beneficiaries")
Main Content Area

Displays the selected section:

Tables show lists of information
Forms allow editing
Action buttons in top-right
Save/Cancel buttons at bottom of forms
Audit Trail

Many screens show audit information:

Created By and Created Date
Last Modified By and Last Modified Date
Hover over fields to see edit history

💡 Tip: Audit trails help track who changed what and when.

Common UI Elements
Buttons

Colors Mean Things:

Blue - Primary actions (Save, Submit, Confirm)
Green - Success actions (Approve, Complete)
Red - Destructive actions (Delete, Cancel, Void)
Gray - Secondary actions (Cancel, Back)
Icons

Common Icons You'll See:

✏️ Pencil - Edit
🗑️ Trash - Delete
👁️ Eye - View
⬇️ Download - Export/Download
🖨️ Printer - Print
➕ Plus - Add New
🔍 Magnifying Glass - Search
⚙️ Gear - Settings
ℹ️ Info - More information
Tables

Most data is shown in tables:

Column Headers - Click to sort
Search Box - Filter results
Pagination - Navigate pages (10, 25, 50, 100 per page)
Row Actions - Edit, Delete, View icons
Forms

When entering data:

Red Asterisk (*) - Required field
Placeholder Text - Example of what to enter
Validation Messages - Appear if something's wrong
Help Icons (?) - Hover for more info
Tips for Efficient Navigation

✅ DO:

Use the search bar for quick member lookup
Open multiple members in separate tabs
Use breadcrumbs to navigate back (when available)
Bookmark frequently used pages

💡 TIPS:

The navigation menu shows all available modules
Recent members appear in search suggestions
Most tables can be sorted and filtered
The hamburger menu provides quick access to all major sections
Common Questions

Q: How do I get back to where I was? A: Use breadcrumbs at the top, or click the back button in your browser.

Q: I accidentally closed a member. How do I find them again? A: Use Global Search (🔍) or check your browser history.

Q: Can I customize the navigation menu? A: No, but your administrator can enable/disable modules based on your organization's configuration and your permissions.

Q: The navigation menu looks different - why? A: You may have different permissions than other users. Some modules are only visible if enabled by your organization or if you have the required access level.

Q: How do I know if changes are saved? A: You'll see a green success message: "Changes saved successfully"
