How Do I Add Multiple Memos to a Member's Record?

Category: Members and Records Time: 5 minutes Difficulty: ⭐ Beginner

Related Topics:

Find a Member
View Audit History
Scan Documents
What This Does

Allows you to add notes, comments, and documentation to a member's record. Memos help track important information, decisions, conversations, and changes that aren't captured elsewhere in the system.

Quick Steps
Find and open the member's profile
Click the Memo button in the top information bar
Click + Memo in the Member Memos window
Select memo type and enter memo details
Click Save Memo
Step-by-Step Instructions
Step 1: Open the Member Profile
Use Global Search or Member Directory
Find the member
Click to open their profile
Step 2: Locate Memos Section

Where to Find It:

Memo Button Location:

The Memo feature is located on the top information bar of the Member Profile screen
Look for the memo icon in the upper-right area of the top bar (where Member Name, Status, DOB, etc. are displayed)
The button displays a memo icon with a count badge if memos exist
Step 3: Add a New Memo
Click the Memo button in the top information bar
The Member Memos window opens
Click + Memo button to create a new memo
Fill in the memo fields
Memo Fields
Required Information

Memo Type*

Select the type of memo from the dropdown
Examples: General, Phone Call, Address Change, Benefit Inquiry, Document Received, etc.
This field is required

Memo Text*

Full details of the note
What happened
Why it's being documented
Any actions taken
This field is required
Optional Information

Follow-up Date

Date when action is needed or follow-up is required
Use this to set reminders for when the memo needs attention
Optional field

Assigned User

Assign the memo to a specific user for action or awareness
Search and select from the list of users
Optional field

Acknowledged

Checkbox to mark that the memo has been reviewed or acknowledged
Useful for tracking which memos have been addressed
Optional field
Step 4: Save the Memo
Review memo content
Click Save
✅ Memo added to member record
Memo appears in memo list
When to Add Memos
Common Reasons for Memos

Document Changes:

"Updated mailing address per member's request"
"Changed bank account - member switched to First National Bank"
"Name changed from Jane Smith to Jane Johnson due to marriage"

Record Conversations:

"Phone call 1/15/2026 - Member asked about retirement eligibility"
"In-person meeting - Discussed beneficiary options"
"Email received regarding contribution question"

Track Issues:

"Member reports missing contribution from March payroll"
"Investigating discrepancy in service credits"
"Waiting for DD-214 to process military buyback"

Note Received Documents:

"Received marriage certificate - filed in documents"
"DD-214 received and scanned"
"Beneficiary form completed and processed"

Explain Corrections:

"Corrected SSN - was entered incorrectly at hire"
"Adjusted DOB - birth certificate showed correct date"
"Fixed contribution amount - calculation error"
Best Practices for Memos
Writing Effective Memos

✅ DO Include:

Date of event or conversation
Who you spoke with
What was discussed or changed
Any actions taken
Any follow-up needed

Good Example:

Memo Type: Phone Call

Memo Text: Spoke with member John Smith on 1/15/2026
at 10:30 AM. Member called asking about retirement
eligibility. I confirmed he has 25 years of service
and is eligible to retire. Sent him retirement
application packet.

Follow-up Date: 1/29/2026
Assigned User: Jane Doe


Poor Example:

Memo Type: General

Memo Text: Talked to member about retirement.

Memo Organization Tips

Use Appropriate Memo Types:

✅ Select "Address Change" memo type for address updates
✅ Select "Phone Call" memo type for phone conversations
❌ Don't use "General" for everything - choose the specific type

Be Specific in Memo Text:

✅ "Updated bank account from Wells Fargo to Chase Bank on 1/15/2026"
❌ "Changed bank"

Include Dates and Context:

✅ "Received beneficiary form on 1/15/2026 and processed same day"
❌ "Got form"
Viewing Existing Memos
Memo List

What You'll See:

Memo Text - Preview of the memo content
Memo Type - Category of the memo (displayed as a pill/badge)
Assigned User - Person assigned to the memo (if any)
Follow-up Date - Due date for follow-up action (if set)
Acknowledged - Checkmark icon if the memo has been acknowledged
Created By - Who added the memo
Date Created - When memo was created

Actions:

Click on any memo in the sidebar to view full details
Edit the selected memo
Delete the selected memo (with proper permissions)
Searching Memos

To Find Specific Memos:

Look for the search box at the top of the memos sidebar
Type keywords to search within memo text, created by, or memo type
Results filter as you type
Click any memo in the filtered results to view its details

💡 Note: The search feature performs a client-side text search across memo content, creator names, and memo types.

Editing or Deleting Memos
To Edit a Memo
Find the memo in the list
Click on the memo (row) to open the edit window
Modify the text
Click Save

💡 Note: You can usually only edit your own memos.

To Delete a Memo
Find the memo in the list
Click on the memo (row) to open the edit window
Click the Delete button (typically bottom left of the window)
Confirm deletion
Memo is removed

⚠️ Warning: Deletion is usually permanent. Delete carefully!

Common Scenarios
Scenario: Documenting a Phone Call

Steps:

Open member profile
Click the Memo button in the top information bar
Click + Memo button
Select Memo Type: "Phone Call"
Enter Memo Text: "Member called 1/15/26 at 2:00 PM asking about purchasing military service. Explained process and costs. Sending information packet."
Set Follow-up Date: 1/29/2026 (if follow-up needed)
Assign User: (optional) Select user to follow up
Click Save Memo
Scenario: Recording Document Receipt

Steps:

Open member profile
Click the Memo button in the top information bar
Click + Memo button
Select Memo Type: "Document Received"
Enter Memo Text: "Received member's DD-214 showing service from 1990-1994, Army, Honorable discharge. Document scanned and attached. Ready to calculate military buyback."
Set Follow-up Date: (if applicable) Date to process the buyback
Assign User: (optional) Person responsible for processing
Click Save Memo
Scenario: Noting a Correction

Steps:

Open member profile
Click the Memo button in the top information bar
Click + Memo button
Select Memo Type: "General"
Enter Memo Text: "SSN Corrected - Changed from 123-45-6788 to 123-45-6789. Original entry was a typo during initial data entry. Member provided Social Security card for verification on 1/15/2026."
Set Follow-up Date: (if follow-up verification needed)
Click Save Memo
Common Questions

Q: Who can see my memos? A: By default, all staff can see memos. Some systems allow private memos visible only to you.

Q: Can I attach files to memos? A: Depends on system. Some allow attachments, others require using the Documents section separately.

Q: How long are memos kept? A: Typically indefinitely. They become part of the member's permanent record.

Q: Can memos be printed? A: Yes, usually you can print the memo list or individual memos.

Q: Should I add a memo for every change? A: Not necessary for changes that are tracked in audit history. Use memos for context, explanations, and information not captured elsewhere.

Troubleshooting
Issue: Can't add memo

Solutions:

Check you have permission to add memos
Verify member record isn't locked
Ensure you're in the correct section
Try refreshing the page
Issue: Memo won't save

Solutions:

Check all required fields are filled
Verify subject isn't too long
Check for special characters causing issues
Try shorter memo text
Best Practices

✅ DO:

Add memos to document important events
Be clear and specific
Include dates and times
Use proper grammar
Note follow-up actions needed

❌ DON'T:

Include confidential information inappropriately
Use memos for casual notes
Leave vague or unclear notes
Use abbreviations others won't understand
Include opinions - stick to facts
