How Do I Find a Member?

Category: Members and Records Time: 5-10 minutes Difficulty: ⭐ Beginner

Related Topics:

Navigate Member Directory
Add a Member
Update Member Information
Before You Begin
You have access to PensionPro+ system
You know either the member's name, employee ID, SSN, or contact information
You have basic search skills
What This Does

Walks you through the two methods to quickly locate and access a member's profile in PensionPro+:

Quick Search - Using the global search field in the header
Member Directory - Browsing the full member list with advanced filtering options

Both methods efficiently streamline member lookup so you can access the correct record instantly.

Quick Steps

Method 1: Quick Search (Global Search)

Click the search field in the header (labeled "Search for members, contact info, beneficiaries...")
Type member name, ID, SSN, phone, email, or beneficiary name
Select member from real-time results
Member profile opens (or open in new tab)

Method 2: Member Directory

Click hamburger menu (☰) → Member Directory or click Member Directory card on homepage
Use search box or click Advanced Search for filters
Apply filters (Gender, Status, Birth Date Range, Hire Date Range, YTD Earnings, etc.)
Click member's name from filtered results
Member profile opens
Understanding Quick Search
Quick Search is Your Fastest Tool

Think of it as a shortcut that searches across all member data fields simultaneously.

Key Features:

✅ Searches Multiple Fields Simultaneously

Member first or last name
Employee ID
Social Security Number (SSN)
Phone number
Email address
Beneficiary details

✅ Real-Time Results

Results display as you type
Shows member name, ID, and status
Displays additional details for quick identification

✅ Instant Profile Access

Click any result to open full profile
Select from multiple matches if name appears multiple times
See employee number and status before opening

✅ Open in New Tab

Click the button next to each result to open in new tab
Compare multiple members at once
Keep search results visible

✅ Convenient Location

Global search field always visible in header
Accessible from any page in system
No navigation required
Method 1: Using Global Search (Fastest)
Step 1: Open Global Search

Where to Find It:

Look in the top navigation bar
Click in the search box (left side after logo)
Search field becomes active
Step 2: Enter Search Terms

You can search by:

Member Name

Type first name, last name, or both
Example: "John Smith" or just "Smith"
Not case-sensitive

Member ID (Employee ID)

Type the member's ID number
Example: "22068" or "12345"

Social Security Number

Last 4 digits: "1234"
Or full SSN: "123-45-6789"
Or partial: "123-45"

Phone Number

Full: "555-123-4567"
Or partial: "555-123"
Searches work and alternate contact info

Email Address

Full: "john.smith@email.com"
Or partial: just domain
Searches primary and alternate emails

Beneficiary Name

Type beneficiary name
Example: "Jane Smith"
Click "Beneficiaries" tab in results

Partial Matches Work!

Type "Sm" → Shows all members with "Sm" in their name
Type "123" → Shows Member ID or SSN containing 123
System finds matches as you type

💡 Tip: Global Search searches across multiple fields simultaneously!

Example Search Results Display:

As you type, results populate below search field:

Results Tabs:

✔ Members tab (selected by default)
Beneficiaries tab (alternative results)
Contacts tab (third-party contacts)

In Members Tab, You See:

Member Name (in bold)
Employee # (ID number)
Status (Active, Retired, Terminated, etc.)

Example Results:

✔ Members    Beneficiaries    Contacts

Name                    Employee #    Status
Peter Adams Member         22068      Withdrawn/Transfer Out
Nina Dulebohn Member       13455      Inactive/Terminated
Herbert Hancock Member      3497      Withdrawn/Withdrawal

Showing 3 of 5 results

Step 3: Select from Results

What You'll See:

List of matching members
Member ID, Name, Status shown
Recent searches appear first

To Open a Member:

Click the member's name in results
Member profile opens immediately
You're ready to work!
Method 2: Using Member Directory
Step 1: Open Member Directory

Where to Go:

Click hamburger menu (☰) → Member Directory
Member Directory opens showing all members
Table view with search and filters
Step 2: Search or Filter

Using the Search Box:

Find the search box at the top of the directory
Type any part of:
First or last name
Member ID
Last 4 of SSN
Results filter as you type
See only matching members

Using Advanced Search Filters:

Click Advanced Search to access filters
Filter options appear along with a "Search for Filter" search box
Available filter categories:

Personal Information Filters:

Gender - Male, Female, Unknown
Marital Status - Single, Married, Unknown
Birth Date Range - From date to To date

Employment Information Filters:

Hire Date Range - From date to To date
Status (Most Recent Status Event) - Enrolled, Retired, Terminated, Active, Inactive, etc.

Financial Information Filters:

YTD Earnings Range - Filter by earnings amount (minimum to maximum)

Additional Filters:

Search for Filter - Search available filters by name
Type specific filter you're looking for

Setting Filter Values:

For Dropdown Filters:

Click dropdown and select value
Example: Gender = "Male", Status = "Retired"

For Date Range Filters:

From Date: Click calendar, select start date
To Date: Click calendar, select end date
Example: Birth Date From 01/01/1960 To 12/31/1965

For Amount Filters:

Enter minimum and maximum amounts
Example: YTD Earnings from $10,000 to $100,000

Combining Multiple Filters:

You can use multiple filters simultaneously:

Gender: Male
Marital Status: Married
Status: Retired
YTD Earnings: $50,000 to $100,000

Results show only members matching ALL criteria.

Table Updates Automatically:

Shows only members matching your filters
Row count displays: "Showing X of Y results"
Remaining members meet all filter criteria

💡 Tip: Clear filters by clicking "Clear All Filters" button or individual X buttons next to each filter.

Step 3: Open the Member

From the Directory:

Find the member in the filtered list
Click their name (blue link)
Member profile opens

Open in New Tab:

Hold Ctrl (Windows) or Cmd (Mac)
Click the member's name
Opens in new tab - keeps directory open
Method 3: Using Recent Members from Global Search
Accessing Recently Opened Member Records

The global search box keeps track of your recently opened member records:

Click in the search box at the top navigation bar
A dropdown appears showing recently opened member records
Click any member's name to open their profile immediately
Quick access to members you've worked with recently

💡 Tip: This is the fastest way to return to a member you were just working with!

Search Tips and Best Practices

✅ BEST PRACTICES:

Use Quick Search for Quick Lookups - It's the fastest method
Use Exact Names When Possible - Reduces false matches
Try Employee ID if Name Uncertain - More reliable identifier
Use Member Directory for Batch Operations - Finding groups of members
Verify Status Before Opening - Know if member is active, retired, etc.
Use Partial Names If Unsure - "Smit" will find "Smith"
Check Multiple Results Carefully - Multiple members may have similar names
Note Employee ID for Future Reference - Use for faster searching next time
Use Global Search for quick lookups
Use Member Directory when browsing groups
Bookmark frequently used members using the star icon in global search
Open multiple members in tabs to compare

❌ DON'T:

Don't Assume Single Match - Verify you have correct member
Don't Use Only Last Name - Too many potential matches
Don't Ignore Status Column - Important for understanding member
Don't Skip Verification - Wrong member could cause errors
Don't Give Up After One Search - Try different search terms
Don't Leave Advanced Filters Applied - Remember to clear when done
Don't Close Tab Without Recording ID - Note the employee ID for future use

💡 PRO TIPS:

Search remembers your recent queries
Browser back button returns to search results
Use partial names when spelling is uncertain
Try ID number if name search fails
Click star icon in global search results to bookmark frequently used members
Common Search Scenarios
Scenario 1: You know the member's full name

Best Method: Global Search

Click the search box in the top navigation
Type "John Smith"
Results display showing all Johns and Smiths
Click on correct John Smith (verify employee # or status)
Profile opens

⏱️ Time: 30 seconds

Pro Tip: Use full name for better results. If "John Smith" shows 5 results, use employee number instead.

Scenario 2: You only know part of the name

Best Method: Member Directory

Go to Member Directory
Type "Smi" in search box
Browse results
Click correct member

⏱️ Time: 15 seconds

Scenario 3: Search by Employee ID

Best Method: Global Search

Situation: You have employee ID 22068 and need member profile

Click the search box in the top navigation
Type "22068"
Results show employee with that ID
Click to open
Correct member profile displays

⏱️ Time: 5 seconds

Result: Peter Adams (Employee #22068) profile opens

Scenario 4: Search by Social Security Number

Best Method: Global Search

Situation: Member calls and provides SSN, you need to find them

Click search field in header
Type SSN "123-45-6789" (full or partial)
Results display member(s) with that SSN
Click to open
Full member record accessible

⏱️ Time: 10 seconds

Note: System finds exact matches even with partial SSN

Scenario 5: Find all retired members

Best Method: Member Directory with Filters

Situation: You need list of all retired members in specific department

Go to Member Directory
Table shows all members initially
Click Advanced Search
Set filters:
Status = "Retired"
Department = your department (if available)
Click filter/search
Table updates showing only matching retired members
Export or review list as needed

⏱️ Time: 10 seconds + browsing

Scenario 6: Find member by partial information

Best Method: Member Directory with Advanced Search

Situation: You know member is "somewhere around 60 years old, female, married"

Navigate to Member Directory
Click Advanced Search
Set filters:
Gender: Female
Marital Status: Married
Birth Date: From 01/01/1960 To 12/31/1965
Results show ~20 members matching criteria
Scan results to find correct member
Click to open profile

⏱️ Time: 2-5 minutes

Common Questions

Q: What if I search and no results appear?

A: Try alternative search methods:

Search by employee ID instead of name
Use partial name (first name or last name separately)
Check spelling carefully
Try beneficiary name if searching for family member
Ask supervisor if member exists in system

Q: What's the difference between Quick Search and Member Directory?

A:

Quick Search = Fast single lookup using search field in header
Member Directory = Full list with filtering options for finding groups

Use Quick Search for one-off lookups, Member Directory for batch operations.

Q: Can I search by phone number or email?

A: Yes! Quick Search searches across multiple fields including:

Phone numbers (full or partial)
Email addresses
Both work and alternate contact info

Q: What if member appears multiple times in results?

A: Check the employee # or status to verify correct member:

Same name but different employee # = different person
Check hire date or department if available
When in doubt, ask the member to confirm their employee #

Q: Can I search for beneficiaries?

A: Yes! Quick Search has separate "Beneficiaries" tab:

Type beneficiary name in search field
Click "Beneficiaries" tab
Results show beneficiaries matching that name
Click to open associated member's profile

Q: What if I can't find a member I know exists? A: Try these steps:

Clear all filters in Member Directory
Try searching by Member ID instead of name
Check spelling of the name
Try searching by last 4 of SSN
Verify you have permission to view that member

Q: Why do some members not appear in search? A: Possible reasons:

You don't have permission to view them
They may be marked inactive or terminated (use filters)
They may be in a different employer group

Q: Can I save favorite members for quick access? A: Yes! PensionPro+ has a built-in favorite/bookmark feature:

Use the global search box at the top to search for a member
When the member appears in the dropdown results, click the star icon next to their name to bookmark them
Bookmarked members will appear at the top of the dropdown the next time you open the search bar
This provides quick access to members you work with frequently

You can also:

Bookmark member profile pages in your browser
Keep frequently used members open in tabs

Q: How do I search for members by employer? A: Use Member Directory with Advanced Search:

Go to Members
Click Advanced Search
Use employer-related filters (if available in your system configuration)
See only that employer's members
Troubleshooting
Issue: Global Search returns no results

Solutions:

Check spelling
Try fewer characters (use partial match)
Try different search term (ID instead of name)
Clear browser cache and try again
Use Member Directory instead
Verify spelling of name
Try searching by employee ID instead
Search by phone or email if available
Use Member Directory advanced search with filters
Check if member status is "Inactive" or "Terminated"
Ask supervisor if member might be in system under different name
Try partial name searches
Issue: Too many search results

Solutions:

Be more specific (use full name)
Add member ID if known
Use Member Directory filters to narrow down
Sort results by status or employer
Try using employee ID instead of name for precision
Use more specific search terms
Add more information (first name AND last name together)
Use filters like Status, Department, or Hire Date
Issue: Search is slow

Solutions:

Wait a moment - large databases take time
Be more specific to reduce results
Use filters to narrow before searching
Contact administrator if consistently slow
Issue: Search field not responding

Solutions:

Refresh browser page
Clear browser cache and cookies
Try different browser
Check internet connection
Verify you're still logged into PensionPro+
Try again in a few moments (might be temporary system issue)
Issue: Wrong member profile opened

Solutions:

Verify you clicked correct result (check employee # carefully)
Go back and search again
Use employee # instead of name for precision
Verify employee # before opening profile
Note: Different people can have same/similar names - always check ID
