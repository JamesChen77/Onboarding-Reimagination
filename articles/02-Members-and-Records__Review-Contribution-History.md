How Do I Review Contribution History?

Category: Members and Records Time: 5 minutes Difficulty: ⭐ Beginner

Related Topics:

Find a Member
Upload Contributions
Export Member Data to Excel
What This Does

Shows you how to view a member's complete contribution history, including employee and employer contributions, dates, amounts, and sources. This information is crucial for verifying service credits and preparing for retirement.

Quick Steps
Find and open the member's profile
Left Navigation Menu → Member History → Deduction / Earns History
View contribution history table
Filter or sort as needed
Export to Excel if needed for analysis
Step-by-Step Instructions
Step 1: Open the Member Profile
Use Global Search or Member Directory
Find the member
Click to open their profile
Step 2: Navigate to Deduction / Earns History

Where to Go:

Look at the left navigation menu
Click Member History section
Click Deduction / Earns History subsection
Contribution history displays

What You'll See:

Table of all deductions and earnings
Sortable columns
Pagination controls
Print button for reports
Step 3: Understanding the Contribution Display

Columns Displayed:

Post Date

Date the deduction/earning was posted
Format: MM/DD/YYYY
Sortable column

Board Name

Retirement board associated with the deduction
May show different boards if member transferred

Pay Amount

Gross payroll amount for the period
Format: $X,XXX.XX
Used as basis for deduction calculations

Deduction Amount

Amount deducted from member's pay
Member's contribution to retirement
Format: $X,XXX.XX

Unit

Organizational unit or department
May change if member transferred

Rate

Contribution rate percentage
Shows rate applied for this deduction
Format: XX%

2% Amount

Incremental deduction amount (2% of base)
Additional contribution amount
Format: $X,XXX.XX

Posting Code

Code identifying the type of posting
Example: Regular, Adjustment, Buyback, etc.

Posting Number

Unique identifier for the posting batch
Used to track and group related postings
Step 4: Sorting and Filtering Contributions

Sorting Columns:

You can sort by clicking on any column header:

Post Date - Sort chronologically
Board Name - Group by retirement board
Pay Amount - Sort by payroll amount
Deduction Amount - Sort by deduction size
Unit - Group by organizational unit
Rate - Sort by contribution rate
2% Amount - Sort by incremental amount
Posting Code - Group by posting type
Posting Number - Sort by batch number

Sorting Tips:

Click column header once for ascending order
Click again for descending order
Default sort is by Post Date (most recent first)
Use Post Date sorting to check for gaps or missing periods
Step 5: Viewing Contribution Details

To See More Information:

Find a contribution in the list
Click on the row
A detailed modal window opens showing:
All deduction/earning fields
Posting information
Board and unit details
Transfer record status
Audit information

What You Can Do:

View complete record details
Edit the record (if you have permissions)
Delete the record (if you have permissions)
See audit trail of changes
Understanding Contribution Information
Contribution Summary

Top of Screen Typically Shows:

Total Employee Contributions: $XXX,XXX.XX Total Employer Contributions: $XXX,XXX.XX Total Service Credits: XX years, XX months

Year-to-Date (YTD):

Current year's contributions
Useful for annual tracking
Types of Contributions

Regular Contributions:

Standard payroll deductions
Most common type
Posted each pay period

Make-Up Contributions:

Payments to purchase past service
Less frequent
May have interest calculations

Buyback Contributions:

Purchasing prior service time
Specific calculation
May be lump sum or installments

Adjustments:

Corrections to previous contributions
May be positive or negative
Should have explanation/note
Common Scenarios
Scenario: Verifying Annual Contributions

Steps:

Open member profile
Navigate to Member History → Deduction / Earns History
Sort by Post Date (chronological order)
Review total deductions for the year
Compare to expected amounts based on pay and rate
Use Print button to generate report if needed for records
Scenario: Checking for Missing Contributions

Steps:

Open member profile
Navigate to Member History → Deduction / Earns History
Sort by Post Date (chronological)
Look for gaps in posting dates
Note any missing periods
Follow up with payroll or employer
Scenario: Preparing for Retirement

Steps:

Open member profile
Navigate to Member History → Deduction / Earns History
Review complete deduction history
Verify all periods are accounted for
Check total deductions and service calculations
Use Print button to generate report for retirement file
Note any discrepancies to resolve
Exporting Contribution History

To Print or Export Contributions:

Navigate to Member History → Deduction / Earns History
Click the Print button in the header
A report generation dialog opens
Configure report options as needed
Generate the report (PDF or other format)
Print or save the report

Common Uses for Reports:

Annual statements
Retirement preparation
Audits
Member requests
Record keeping

💡 Tip: The Print button generates a formatted report of the deduction/earnings history for the member.

Interpreting Contribution Data
Service Credit Calculations

Understanding Service Credits:

Usually based on hours worked or salary
May vary by member type
1.0 = Full year of service
0.5 = Half year of service

Checking Accuracy:

Full-time members should accrue ~1.0 per year
Part-time members accrue proportionally
Gaps should align with leaves of absence
Contribution Rate Verification

Typical Checks:

Employee Contribution:

Should match specified percentage
Example: 9% of gross salary
Calculate: Salary × Rate = Expected Contribution

Employer Contribution:

Should match employer's rate
May be same as employee or different
Verify against contract or plan documents
Common Questions

Q: Why are there gaps in contribution history? A: Common reasons include:

Leave of absence
Part-time or seasonal employment
Periods of non-covered employment
System conversion from old system

Q: What if contributions look incorrect? A: Contact your contributions or payroll department. They can investigate and make corrections if needed.

Q: Can I see contributions from previous employers? A: Yes, if they're in the same pension system. Use employer filter to separate them.

Q: What's the difference between posted and pending? A: Posted contributions are finalized. Pending are uploaded but not yet finalized.

Q: Can members see their own contribution history? A: Depends on your member self-service setup. Contact your administrator.

Troubleshooting
Issue: Contribution history is empty

Solutions:

Verify member has employment history
Check if contributions have been uploaded
Verify date filters aren't excluding data
Check member status (must be active or have past activity)
Contact administrator if data should be present
Issue: Contribution amounts seem wrong

Solutions:

Verify member's contribution rate
Check if salary information is correct
Look for adjustment entries
Compare to pay stubs
Report discrepancy to payroll/contributions team
Issue: Can't export contributions

Solutions:

Check you have export permissions
Try removing filters and exporting again
Try smaller date range
Use different browser if export fails
Contact IT support
Best Practices

✅ DO:

Review contribution history regularly
Verify service credits are accurate
Export history for important milestones
Report discrepancies promptly
Keep records of exports for audits

💡 TIPS:

Use sorting to organize data by different columns
Sort by Post Date to check chronologically
Compare deduction amounts to pay amounts and rates
Verify before processing retirement

Documentation Rule

⚠️ Important for Documentation Maintainers:

When documenting contribution/deduction history functionality, always validate navigation paths and column names against the codebase. The correct navigation path is:

Left Navigation Menu → Member History → Deduction / Earns History

The columns displayed are: Post Date, Board Name, Pay Amount, Deduction Amount, Unit, Rate, 2% Amount, Posting Code, Posting Number

The export button is labeled "Print", not "Export" or "Download". Always verify UI elements against the actual component implementation (member-dedearn-history.component.html and .ts).
