How Do I Upload/Scan Documents in PensionPro+?

Category: Members and Records Time: 5-10 minutes Difficulty: ⭐⭐ Intermediate

Before You Begin:

Organization board must have enabled the Scanning feature
Scanner must be connected to your computer and turned on (if scanning)
Physical documents should be prepared (unstapled, flat)
First Time Users: "Dynamic Web TWAIN" service must be installed (see Prerequisite below)

Related Topics:

Find a Member
Add Multiple Memos
Update Beneficiary Designations
What This Does

Allows you to scan physical documents directly into PensionPro+ and attach them to specific member records. This creates a secure digital archive of essential member documents (like birth certificates, beneficiary forms, or affidavits) accessible directly from the member's profile.

Allows you to digitize paper documents and upload digital files (PDFs, images) and attach them to member records for easy access, compliance, and record-keeping.

Quick Steps
Open member profile
Click Documents navigation card
Click Scan / Upload Documents button
Choose file from computer or scan
Enter document details (title, category, keywords)
Click Save
Document appears in member's document list
Step-by-Step Instructions
Step 1: Navigate to Member's Documents

Open the member profile:

Find the member using Find a Member
Member profile opens

Go to Documents section:

Look at navigation cards on the left side
Click Documents
Documents page displays with list of existing documents
Step 2: Start Upload Process

On the Documents page:

Look for Scan / Upload Documents button (top-right area)
Button shows upload icon 📤
Click the button
Upload modal/dialog opens
Step 3: Select Your File

You have options:

Option A: Upload Existing Digital File

Use when: You already have a PDF, image, or scanned file on your computer

Click Choose File or Browse button
File browser opens
Navigate to your file
Select the file
Click Open
Filename appears in upload dialog

Supported file types:

PDF (.pdf) - Recommended
Images (.jpg, .jpeg, .png, .gif)
TIFF (.tif, .tiff)
Other common document formats (check system settings)

File size limits:

Maximum: Usually 10-25 MB per file
Check with administrator for your system's limit
Option B: Scan Using Connected Scanner

Use when: You have paper document and scanner connected

Ensure scanner is connected and powered on
Place document in scanner
In upload dialog, look for Scan button or option
Click Scan
Scanner initiates
Scanned image appears in dialog
Preview the scan
Re-scan if needed

💡 Tip: Check scanner is properly installed and configured with your computer before attempting to scan.

Step 4: Enter Document Information

Required Fields:

Title/Description

Enter descriptive name for document
Example: "Beneficiary Form 2024"
Example: "Medical Records - Heart Exam"
Be specific - you'll search by this later!

Category (Dropdown)

Select document type from list
Common categories include:
Beneficiary Forms
Medical Records
Correspondence
Birth Certificates
Marriage Certificates
Death Certificates
Military Records
Court Orders
Tax Forms
Other

Optional Fields:

Keywords

Select keywords from checkbox dropdown
Choose multiple applicable tags
Helps find document later
⚠️ Note: Keywords are pre-defined selections rather than free text entry

Scan Date (Auto-filled)

Usually today's date
Can be changed if needed
Format: MM/DD/YYYY

Notes (if available)

Additional context about document
Why it was uploaded
Any special instructions
Step 5: Save the Document
Review all entered information
Verify correct file is selected
Click Save or Upload button
Progress bar may appear for large files
Wait for upload to complete

What happens:

✅ File uploads to server
✅ Document information saved
✅ Document attached to member record
✅ Success message appears
✅ Modal closes
✅ Document list refreshes showing new document
Step 6: Verify Upload

After saving:

Document list automatically refreshes
Your new document appears in the table
Check document details:
Title displays correctly
Category is correct
Scan date shows
Keywords visible (if table includes them)

To view the uploaded document:

Click the document row in table
OR click download/view icon
Document opens in new tab or downloads
Verify it's correct file
Document Management Features
Viewing Existing Documents

On the Documents page:

Document list shows:

Title/Description
Category
Keywords
Scan Date
Actions (download, view, etc.)

To view a document:

Click document row
OR click view/download icon
Document opens or downloads

Filter documents:

Use filter fields above table:
Title (text search)
Keywords (dropdown)
Category (dropdown)
Scan Date Range (date picker)
Results filter as you enter criteria
Click Reset Filters to clear
Organizing Documents

Use consistent naming:

Include document type
Include date if relevant
Be descriptive

Examples of good titles:

"Beneficiary Designation - John Smith - 2024-03-15"
"Annual Affidavit - 2024"
"Medical Clearance - Dr. Johnson - March 2024"
"Court Order - DRO - Case 12345"

Use categories correctly:

Select most specific category available
Consistent categorization helps searching
If unsure, choose "Other" and use descriptive title

Add keywords:

Think about how you'll search for this later
Include year
Include type of form
Include related party names if relevant
Downloading Documents

To download a document:

Find document in list
Click download icon (⬇️) in Actions column
OR click the row, then click download in viewer
File downloads to your Downloads folder
Open from there
Common Scenarios
Scenario 1: Upload Beneficiary Form

Goal: Attach completed beneficiary designation form to member record

Steps:

Open member profile
Click Documents navigation card
Click Scan / Upload Documents
Choose File: Beneficiary_Form_Signed.pdf
Enter Title: "Beneficiary Designation - 2024-12-15"
Select Category: "Beneficiary Forms"
Add Keywords: "beneficiary, designation, 2024"
Click Save

Result: Form attached, easily findable in future

⏱️ Time: 3 minutes

Scenario 2: Scan Paper Medical Record

Goal: Digitize and upload paper medical documentation

Steps:

Open member profile
Click Documents
Click Scan / Upload Documents
Place medical form in scanner
Click Scan button
Preview scanned image
Enter Title: "Medical Exam - Dr. Anderson - 2024-10-20"
Select Category: "Medical Records"
Add Keywords: "medical, exam, disability, 2024"
Click Save

Result: Paper document now digitally stored and accessible

⏱️ Time: 5 minutes

Scenario 3: Upload Multiple Related Documents

Goal: Upload entire packet of retirement paperwork

Steps:

Open member profile
Click Documents
For each document:
Click Scan / Upload Documents
Select file
Enter details with consistent naming:
"Retirement App - Page 1"
"Retirement App - Page 2"
"Retirement App - Tax Elections"
Use same category: "Retirement Forms"
Use same keywords: "retirement, application, 2024"
Save each
All documents now grouped by keywords and category

Result: Complete retirement packet digitized and organized

⏱️ Time: 15 minutes for 5-10 documents

Scenario 4: Find and View Old Document

Goal: Locate beneficiary form from 3 years ago

Steps:

Open member profile
Click Documents
Use filters:
Category = "Beneficiary Forms"
Keywords = "beneficiary"
Scan Date Range: 2021-2022
Results filter to matching documents
Click document to view

Result: Found archived document quickly

⏱️ Time: 2 minutes

Best Practices

✅ DO:

Scan documents as soon as received (don't let them pile up)
Use descriptive, consistent naming conventions
Include dates in titles when relevant
Select appropriate category every time
Add keywords to make finding documents easier
Verify upload completed successfully
Check document quality before saving (readable scan)
Keep original paper documents per policy
Upload documents to correct member (verify before saving!)

❌ DON'T:

Upload unclear or illegible scans (rescan if poor quality)
Use vague titles like "Form" or "Document"
Forget to categorize documents
Upload documents to wrong member (double-check!)
Upload files with viruses (scan your computer regularly)
Upload inappropriate content
Share member documents with unauthorized people
Delete uploaded documents without proper authorization

💡 PRO TIPS:

Scan batches of documents at once for efficiency
Create naming convention guide for your office
Use OCR (Optical Character Recognition) software before uploading for searchable PDFs
If uploading multiple pages, consider combining to single PDF first
Add keywords as if someone else needs to find this document
Include your initials in keywords if multiple staff upload documents
Set up document retention schedule with administrator

Common Questions

Q: Can I upload multiple files at once? A: This depends on your system. Most require uploading one at a time, but the process is quick. Check with administrator about batch upload features.

Q: What happens if I upload the wrong file? A: Contact your administrator about deleting/replacing documents. Most systems have edit or delete capabilities with proper permissions.

Q: Can I edit document information after uploading? A: Usually yes! Click the document, look for Edit option, update information, save changes.

Q: How do I know if a document uploaded successfully? A: You'll see:

Success message appears
Document appears in the list
No error messages displayed

Q: What if my scanner isn't working? A: Scan on another computer/scanner, save file, then upload the saved file using "Choose File" option.

Q: Can other staff see documents I upload? A: Yes, anyone with document access for that member can view uploaded documents. Use appropriate security practices.

Q: What resolution should I scan at? A: 200-300 DPI is sufficient for most documents. Higher resolution = larger file size.

Q: Can I scan both sides of a document? A: Yes! Either:

Scan each side separately and upload as separate documents
Use duplex scanning if your scanner supports it
Create a multi-page PDF with both sides

Q: How long are documents retained? A: Retention varies by document type and organization policy. Check with your administrator.

Q: Can I scan documents in color? A: Yes, but black & white is usually sufficient and creates smaller files. Use color for photos or when color is important.

Troubleshooting
Issue: Scanner not detected

Solutions:

Verify scanner is powered on
Check USB/network connection
Install/update scanner drivers
Test scanner with other application
Use file upload instead of direct scan
Contact IT support
Issue: File upload fails

Solutions:

Check file size (may exceed limit)
Check file format (PDF recommended)
Check internet connection
Try different file format
Try smaller file or compress PDF
Refresh page and try again
Contact administrator if issue persists
Issue: Scanned document is illegible

Solutions:

Clean scanner glass
Rescan at higher resolution (300 DPI)
Ensure document is flat on scanner
Check scanner settings (brightness, contrast)
Rescan and re-upload
If still poor, photograph with good camera instead
Issue: Can't find uploaded document

Solutions:

Clear all filters on Documents page
Check spelling of title/keywords
Try different category filter
Expand date range filter
Verify you uploaded to correct member
Contact administrator if truly missing
Issue: Document won't open after upload

Solutions:

Check file wasn't corrupted during upload
Try downloading instead of viewing in browser
Try different browser
Verify file format is supported
Re-upload if necessary
Contact IT support
Issue: Wrong category selected

Solutions:

Click the document to view/edit
Look for Edit option
Change category to correct one
Save changes
If no edit option, contact administrator
Security Reminders

Only upload documents to correct member record
Verify information before uploading
Don't share documents with unauthorized individuals
Follow your organization's data security policies
Report any security concerns to administrator
