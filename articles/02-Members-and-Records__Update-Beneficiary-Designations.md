How Do I Update Beneficiary Designations?

Category: Members and Records Time: 10 minutes Difficulty: ⭐⭐ Intermediate

Related Topics:

Find a Member
Add a Member
Scan Documents
What This Does

Allows you to add, modify, or remove beneficiary designations for a member. Beneficiaries are individuals who may receive survivor benefits or death benefits if the member passes away.

Quick Steps
Find and open the member's profile
Navigate to Demographic Data → Beneficiary Info
Click + Beneficiary to add, or click an existing beneficiary record to edit
Enter beneficiary information
Specify benefit percentage
Click Save
Understanding Beneficiaries
Primary vs. Contingent Beneficiaries

Primary Beneficiaries (Primary field = "Yes"):

First in line to receive benefits
Receive benefits if member passes away
Must total 100% allocation

Contingent Beneficiaries (Primary field = "No"):

Receive benefits if primary beneficiaries are deceased
Backup to primary beneficiaries
Should also total 100%
Common Beneficiary Types (Relationship)

The Type field indicates the relationship to the member:

Spouse
Child/Children
Parent
Sibling
Other Relative
Trust or Estate
Charity/Organization
Step-by-Step Instructions
Step 1: Open the Member Profile
Use Global Search or Member Directory
Find the member
Click to open their profile
Step 2: Navigate to Beneficiaries

Where to Go:

Click Demographic Data section in the left navigation
Click Beneficiary Info
Current beneficiaries display (if any)
Step 3: Add a New Beneficiary
Click the + Beneficiary button
The "Beneficiary Info Add" window opens
Fill in required information

Managing Multiple Beneficiaries
Adding Multiple Primary Beneficiaries

Example: Spouse and Two Children

Add Spouse

Type: Select "Spouse"
Primary: Select "Yes"
Percentage: 50%
Click Save

Add Child 1

Type: Select "Child"
Primary: Select "Yes"
Percentage: 25%
Click Save

Add Child 2

Type: Select "Child"
Primary: Select "Yes"
Percentage: 25%
Click Save

Total Must Equal 100%

Adding Contingent Beneficiaries

When to Use:

Backup if primary beneficiaries are deceased
Additional protection for the member's wishes

Example:

Add Sibling
Type: Select "Sibling"
Primary: Select "No" (makes this a contingent beneficiary)
Percentage: 100%
Click Save
Editing Existing Beneficiaries

To Modify a Beneficiary:

Find the beneficiary in the list
Click on the beneficiary record (row)
The "Beneficiary Info Edit" window opens
Update the information as needed
Click Save

Common Changes:

Update address/contact info
Change percentage allocation
Update Type (relationship)
Change Primary status (Yes/No)
Removing a Beneficiary

To Delete a Beneficiary:

Find the beneficiary in the list
Click on the beneficiary record to open the "Beneficiary Info Edit" window
Click the Delete button (bottom left of the window)
Confirm deletion when prompted
Beneficiary is removed

⚠️ Important: Adjust remaining beneficiaries' percentages to total 100%!

Important Considerations
Total Allocation Rules

✅ Primary beneficiaries must total:

100% when using percentages
or specific amounts that match expected benefits

✅ Contingent beneficiaries should total:

100% for complete designation

⚠️ System may prevent saving if totals don't match!

Required Documentation

Best Practice - Attach Documents:

Beneficiary designation form (signed)
Marriage certificate (for spouse)
Birth certificates (for children)
Any legal documentation

When to Update Beneficiaries

Common Life Events:

Marriage or divorce
Birth or adoption of child
Death of beneficiary
Change in relationship
Member request

Recommended Review:

Annually
After major life events
Before retirement
Common Scenarios
Scenario: Member Gets Married

Steps:

Open member profile
Go to Demographic Data → Beneficiary Info
If other beneficiaries exist, adjust percentages
Click + Beneficiary to add new spouse:
Enter spouse's name (First Name, Last Name)
Type: Select "Spouse" (in Beneficiary Info section)
Primary: Select "Yes"
Percentage: (member's choice, e.g., 100%)
Click Save
Adjust or remove previous beneficiaries as needed
Attach marriage certificate
Scenario: Member Has a Child

Steps:

Open member profile
Go to Demographic Data → Beneficiary Info
Click + Beneficiary to add new child:
Enter child's name (First Name, Last Name)
Birth Date: Child's birth date
Type: Select "Child" (in Beneficiary Info section)
Primary: Select "Yes" if primary beneficiary
Redistribute percentages among all children and spouse
Click Save
Attach birth certificate
Scenario: Beneficiary Passes Away

Steps:

Open member profile
Go to Demographic Data → Beneficiary Info
Click on the deceased beneficiary record
The "Beneficiary Info Edit" window opens
Either:
Enter the Death Date in the Personal Info section, OR
Click Delete to remove the beneficiary
Click Save
Redistribute percentages to remaining beneficiaries
Document in member memos
Validation and Errors
Common Validation Messages

"Primary beneficiaries must equal 100%"

Add up all primary percentages
Adjust to equal exactly 100%
Save again

"Social Security Number already exists"

SSN may be used for another member
Verify SSN is correct
Contact administrator if issue persists

"Invalid date format"

Use MM/DD/YYYY format
Ensure date is realistic
Cannot be future date for DOB
Common Questions

Q: Can a member have no beneficiaries? A: Yes, but it's not recommended. Benefits would go to estate or per system rules.

Q: Can a minor child be a beneficiary? A: Yes, but a guardian should be designated to manage benefits.

Q: Can a member name a trust as beneficiary? A: Yes, enter trust name and trustee information.

Q: What if percentages don't divide evenly? A: Use decimals (e.g., 33.33%, 33.33%, 33.34% for three equal shares).

Q: Can beneficiaries be changed after retirement? A: Rules vary. Consult your administrator about post-retirement changes.

Q: Who can request beneficiary changes? A: Only the member can designate beneficiaries. Require signed authorization.

Troubleshooting
Issue: Can't save - percentages don't total 100%

Solutions:

Add up all primary beneficiary percentages
Adjust amounts to equal exactly 100%
Use calculator if needed
Round to 2 decimal places
Issue: System won't accept SSN

Solutions:

Verify SSN format (XXX-XX-XXXX)
Check for typos
Confirm SSN isn't already in use
Contact administrator for duplicates
Issue: Can't delete beneficiary

Solutions:

Check if beneficiary is referenced elsewhere
Verify you have delete permissions
Contact administrator if locked
Best Practices

✅ DO:

Request signed beneficiary forms
Verify beneficiary information
Ensure percentages total 100%
Attach supporting documents
Review beneficiaries annually
Document all changes in memos

❌ DON'T:

Make changes without member authorization
Skip documentation
Leave percentages unbalanced
Forget to update after life events
