How Do I Update Contact Information?

Category: Members and Records Time: 5 minutes Difficulty: ⭐ Beginner

Related Topics:

Find a Member
Update Member Demographic Information
Add Multiple Memos
What This Does

Allows you to update a member's mailing address, phone numbers, email address, and contact preferences. Keeping contact information current ensures members receive important communications.

Quick Steps
Find and open the member's profile
Navigate to Demographic Data → Contact Info
Click Edit button
Update address, phone, or email
Click Save
Step-by-Step Instructions
Step 1: Open the Member Profile
Use Global Search or Member Directory
Find the member
Click to open their profile
Step 2: Navigate to Contact Information

Where to Go:

Click Demographic Data section in the left navigation
Click Contact Info
Current contact information displays
Step 3: Edit Contact Information
Click the Edit button (top-right)
Fields become editable
Update as needed

Primary Address:

Primary Address Line 1 - Street address
Primary Address Line 2 - Apt/Unit number (optional)
City - City name
State - Select from dropdown
ZIP Code - 5 or 9 digit ZIP

Seasonal Address:

Alternate/Seasonal Address Line 1 - Seasonal street address
Alternate/Seasonal Address Line 2 - Apt/Unit (optional)
Alternate/Seasonal City - City name
Alternate/Seasonal State - Select from dropdown
Alternate/Seasonal ZIP Code - 5 or 9 digit ZIP
Alternate/Seasonal Begin Month - Start month for seasonal address
Alternate/Seasonal Begin Day - Start day
Alternate/Seasonal End Month - End month for seasonal address
Alternate/Seasonal End Day - End day
Seasonal Foreign Address - If applicable

Seasonal Contact Info:

Seasonal Email 1 - Primary seasonal email
Seasonal Email 2 - Secondary seasonal email
Seasonal Phone 1 - Primary seasonal phone
Seasonal Phone 2 - Secondary seasonal phone

Miscellaneous:

Email Address 2 - Alternate email address
Phone 3 (Fax) - Fax number
Foreign Address - International address if applicable
Comments - Additional notes about contact information
Step 4: Save Changes
Review all updates
Click Save
✅ Confirmation message appears
Contact information updated
Address Change Best Practices

When Updating Addresses:

Verify the new address is complete and correct
For seasonal addresses, ensure begin/end dates are specified
Consider adding a memo with the change date and reason
If member is retired, verify address for check mailing

Address Validation Tips:

Use USPS format for US addresses
Include apartment/unit numbers in Address Line 2
Use standard state abbreviations
Verify ZIP code is correct for city
For foreign addresses, use the Foreign Address field
Phone Number Formatting

System Accepts:

(555) 555-5555
555-555-5555
5555555555

Best Practice: Use consistent format (555) 555-5555

💡 Tip: System may auto-format phone numbers when you save.

💡 Note: Primary phone numbers are stored in the Basic Info section under Demographic Data. The Contact Info section includes seasonal phones and fax numbers.

Email Address Requirements

Valid Email Format:

Must contain @ symbol
Must have domain (.com, .org, etc.)
Example: john.smith@email.com

Best Practices:

Use personal email for retirees
Use work email for active members (if appropriate)
Verify spelling carefully
Test email delivery after updating

💡 Note: Primary email address is stored in the Basic Info section under Demographic Data. The Contact Info section includes Email Address 2 and seasonal emails.

Common Scenarios
Scenario: Member is Moving

Steps:

Open member profile
Go to Demographic Data → Contact Info
Click Edit
Update Primary Address fields (street, city, state, ZIP)
Add memo: "Address updated due to relocation"
Save

💡 Tip: If member has both a primary and seasonal address, update both if applicable.

Scenario: Member Changed Phone Number

Steps:

Open member profile
Go to Demographic Data → Basic Info (for primary phone)
Click Edit
Update phone number
Verify format
Save

💡 Note: For seasonal or fax numbers, use Contact Info section instead of Basic Info.

Scenario: Member Wants Email Communication

Steps:

Open member profile
Go to Demographic Data → Basic Info (for primary email)
Click Edit
Enter/verify primary email address
Save
If additional email needed, go to Contact Info and add Email Address 2

💡 Tip: Primary email is in Basic Info; additional or seasonal emails are in Contact Info.

Scenario: Member Has a Seasonal Address (Snowbird)

Steps:

Open member profile
Go to Demographic Data → Contact Info
Click Edit
Enter Alternate/Seasonal Address (street, city, state, ZIP)
Set Alternate/Seasonal Begin Month and Day (e.g., October 15)
Set Alternate/Seasonal End Month and Day (e.g., April 30)
Optionally add Seasonal Email and Phone numbers
Save

💡 Tip: System can automatically use seasonal address during specified date ranges for mailings.

What Happens When You Save

System Actions:

✅ Validates address format
✅ Validates phone number format
✅ Validates email format
✅ Creates audit trail
✅ Updates member record
✅ Shows success message

Communications Impact:

Future mailings go to primary address (or seasonal address during specified dates)
Email communications use primary email from Basic Info
Seasonal contact information is used during seasonal address active dates
Common Questions

Q: Do I need to notify anyone when changing a member's address? A: For retired members receiving checks, notify payroll/accounting team. For significant changes, add a memo to the record.

Q: Can I have multiple addresses for one member? A: Yes! The Contact Info section allows for both a primary address and a seasonal/alternate address with specific date ranges.

Q: How do seasonal addresses work? A: Enter begin/end month and day for when the seasonal address should be active. System automatically uses the appropriate address based on current date.

Q: Where do I update the primary phone and email? A: Primary phone and email are in Basic Info under Demographic Data. Contact Info is for additional/seasonal contact details.

Q: What if the member doesn't have an email address? A: Leave the email field blank. It's optional.

Q: Can members update their own contact information? A: Only if your system has member self-service enabled. Otherwise, staff must make updates.

Q: How do I know if mail is being returned? A: Check for returned mail notifications or memos on the member record. Contact your mail processing team.

Q: What is the Foreign Address field for? A: Use this field for international addresses that don't fit the standard US address format.

Troubleshooting
Issue: Address won't save

Solutions:

Check all required fields are filled
Verify ZIP code matches city/state
Remove special characters if present
Try standard abbreviations (St., Ave., Blvd.)
Issue: Email format invalid

Solutions:

Check for @ symbol
Verify domain extension (.com, .org)
Remove spaces
Check for typos
Issue: Phone number format rejected

Solutions:

Use format: (555) 555-5555
Remove letters or special characters
Ensure 10 digits for US numbers
Include area code
Best Practices

✅ DO:

Verify address spelling with member
Use standard USPS format
Keep email addresses current
Add memo when making changes
Test new email addresses

❌ DON'T:

Use abbreviations unless standard
Enter incomplete addresses
Skip phone area codes
Forget to save changes
