How Do I Update Member Demographic Information?

Category: Members and Records Time: 5 minutes Difficulty: ⭐⭐ Intermediate

Related Topics:

Find a Member
Update Contact Information
View Audit History
What This Does

Allows you to modify a member's basic demographic information such as name, Social Security Number, date of birth, gender, and marital status. This ensures member records stay accurate and up-to-date.

Quick Steps
Find and open the member's profile
Navigate to Personal Information section
Click Edit button
Update the demographic fields
Click Save
Changes are recorded with audit trail
Before You Begin

Important Considerations:

⚠️ Changing certain fields may require documentation:

Name changes (marriage, legal name change)
SSN corrections (requires verification)
Date of birth corrections (requires proof)

💡 Tip: Have supporting documentation ready before making changes.

Step-by-Step Instructions
Step 1: Open the Member Profile

Find the Member:

Use Global Search in the top navigation
Type member name or ID
Click to open member profile

See:
Find a Member

Step 2: Navigate to Personal Information

Where to Go:

Look at the navigation cards on the left side
Navigate to Demographic Data section
Member's demographic information displays

What You'll See:

Current name, SSN, DOB
Gender and marital status
Other demographic data
Edit button (top-right)
Step 3: Click Edit

To Modify Information:

Look in the top-right corner of the section
Click the Edit button (pencil icon ✏️)
Form fields become editable
Current values are pre-filled
Step 4: Update Demographic Fields

About Demographic Fields:

The demographic fields available for editing are configured and managed by your board's administrators. The specific fields you see may vary based on your organization's requirements and configuration.

Common field types include:

Name information (first, middle, last, suffix)
Identification numbers (SSN, member ID)
Personal data (date of birth, gender, marital status)
Contact preferences

💡 Tip: Required fields are marked with an asterisk (*).

⚠️ Need Different Fields? If you need to add, remove, or modify the available demographic fields, contact your administration team.

Step 5: Review and Save

Before Saving:

Double-check all changes
Verify SSN if changed
Confirm DOB is correct
Review name spelling

To Save:

Click the blue Save button
Wait for confirmation message
✅ "Changes saved successfully" appears
Form returns to view mode

To Cancel:

Click Cancel button
No changes are saved
Form returns to view mode
Special Considerations
Changing a Member's Name

Common Reasons:

Marriage or divorce
Legal name change
Correction of data entry error

Best Practice:

Update the name fields
Add a memo documenting the change
See: Add Multiple Memos
Attach supporting documentation
Marriage certificate
Court order
Legal name change document
Save changes
Correcting Social Security Number

Extra Care Required:

⚠️ WARNING: Changing SSN affects:

Contribution records
Tax reporting
Benefit calculations
Historical data linking

Steps:

Verify the correct SSN
Document why the change is needed
Notify your administrator
Update the SSN field
Add memo explaining the correction
Save changes

💡 Tip: Always have administrator approval for SSN changes.

Updating Date of Birth

Common Scenarios:

Initial data entry error
Official record correction

Requirements:

Proof of correct date (birth certificate, passport)
Documentation of why change is needed

Impact:

May affect retirement eligibility
Changes benefit calculations
Updates age-related restrictions
What Happens When You Save

System Actions:

✅ Validates all fields
✅ Checks for duplicate SSN (if changed)
✅ Creates audit trail entry
✅ Updates member record
✅ Refreshes member banner
✅ Shows success message

Audit Trail Created:

Who made the change
When it was made
What was changed
Old value and new value

See:
View Audit History

Validation Rules

The system checks:

Social Security Number:

Must be 9 digits
Format: XXX-XX-XXXX
Must be unique in system
Cannot be all zeros

Date of Birth:

Must be valid date
Cannot be in the future
Member must be at least 16 years old (typical)
Cannot be more than 100 years ago (typical)

Names:

Cannot be blank for required fields
Maximum length: 50 characters each
Special characters may be restricted
Common Questions

Q: Can I change multiple members at once? A: No, demographic changes must be made individually to ensure accuracy and proper documentation.

Q: Will changing the name affect historical records? A: No, historical records maintain their original values. The audit trail shows the change history.

Q: Do I need permission to update demographic information? A: Yes, you need appropriate permissions. Contact your administrator if you can't edit.

Q: What if the SSN I enter already exists? A: System will show an error. Verify the correct SSN and check if a duplicate member exists.

Q: Can I undo a change? A: Not automatically. You'll need to manually change it back. Always verify before saving!

Q: How long does it take for changes to appear? A: Immediately. Changes are reflected as soon as you save.

Troubleshooting
Issue: Can't click Edit button

Solutions:

Check you have edit permissions
Verify member record isn't locked
Confirm you're viewing the correct section
Contact administrator if button is missing
Issue: Save button is grayed out

Causes:

No changes were made
Required fields are empty
Validation errors exist

Solutions:

Check for red error messages
Fill in all required fields (*)
Fix any validation errors
Try making a change to enable Save
Issue: SSN won't save

Solutions:

Verify format is XXX-XX-XXXX
Check SSN doesn't already exist
Ensure all 9 digits are entered
Contact administrator for SSN conflicts
Best Practices

✅ DO:

Verify information before making changes
Document the reason for changes in memos
Attach supporting documents when available
Double-check SSN and DOB changes
Review audit trail after saving

⚠️ DON'T:

Change SSN without verification
Make changes without documentation
Rush through demographic updates
Forget to add explanatory memos
