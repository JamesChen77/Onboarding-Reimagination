How Do I View the Audit History for Member or Employer Information?

Category: Members and Records Time: 2-5 minutes Difficulty: ⭐ Beginner

Before You Begin:

Ensure you have access to the member profile or record you wish to investigate
Identify the specific information card (e.g., Contact Information, Basic Information) containing the data field you want to review

Related Topics:

Find a Member
Update Member Information
Add Multiple Memos
What This Does

Allows you to review the comprehensive change history for any specific information displayed on a card within PensionPro+. This feature tracks modifications to key data fields, identifying who made the changes, when they were made, and what the previous values were. It is essential for maintaining data integrity and troubleshooting discrepancies.

Shows you the complete history of changes made to a member's record, including who made changes, when they were made, and what the old and new values were. This audit trail ensures transparency and accountability.

Quick Steps
Find and open the member's profile
Look for audit icon or "History" option
Click to view audit trail
See list of all changes with dates and users
Click individual entries for details
Step-by-Step Instructions
Step 1: Open the Member Profile
Use Global Search or Member Directory
Find the member
Click to open their profile
Step 2: Access Audit History

Method: Audit History Button

Look for "Audit History" or "History" button
Usually in top-right of section
Click to open full audit trail
Complete list of changes displays
Understanding Audit Information
What You'll See

For Each Change:

Date/Time

When the change was made
Includes date and time stamp
Example: "01/15/2026 2:30 PM"

User

Who made the change
Shows user's email address
Example: "john.administrator@agency.gov"

Process Name

Which process or area was affected
Example: "Member Demographics", "Financial Information"

Field Changed

Which field was modified
Example: "Last Name"

Old Value

What the value was before
Example: "Smith"

New Value

What the value is now
Example: "Johnson"
Audit History Display

Typical Layout:

Date/Time         User                      Process Name          Field          Old Value   New Value
01/15/26 2:30 PM  jane.admin@agency.gov     Member Demographics   Last Name      Smith       Johnson
01/10/26 10:15 AM mike.staff@agency.gov     Contact Information   Address        123 Oak St  456 Main St
12/20/25 3:45 PM  jane.admin@agency.gov     Member Demographics   SSN            ***-**-1234 ***-**-5678

Common Uses for Audit History
Verify Changes

Check Who Changed What:

Open audit history
Find the field of interest
See who made the change
Verify change was authorized

Example Use: "Member says their address was changed without permission. Check audit history to see who made the change and when."

Track Data Corrections

Document Error Fixes:

View audit history
See original incorrect value
See corrected value
Identify when correction was made

Example Use: "SSN was entered wrong at hire. Audit trail shows original entry and correction date for documentation."

Compliance and Accountability

Maintain Records:

Audit trails provide proof of changes
Required for many compliance standards
Shows proper procedures were followed
Documents authorization for sensitive changes
Filtering Audit History

Common Filters:

By Date Range:

Select start date
Select end date
View changes in that period

By User:

Select specific user from dropdown
See only that user's changes

By Field:

Select field name
See only changes to that field

If Export is Available:

Open audit history

Look for Export or Download button
Select format (Excel, PDF, CSV)
File downloads

Uses for Exports:

Compliance audits

Training examples
Long-term archiving

Common Questions

Q: How far back does audit history go? A: Typically since system implementation. Older data may have limited history if migrated from previous system.

Q: Can audit history be deleted? A: No. Audit trails are permanent and cannot be deleted for compliance reasons.

Q: Who can see audit history? A: Usually all authorized staff. Some systems restrict sensitive audit data to administrators.

Q: What if audit history shows unauthorized changes? A: Report to your supervisor or administrator immediately for investigation.

Q: Does audit history track views (not just changes)? A: Depends on system. Most track changes only, but some log data access as well.

Privacy and Security

Protected Information:

Social Security Numbers may show partially masked
Sensitive fields may have restricted audit access
Passwords/PINs never shown in audit trails

Access Control:

Audit viewing may require specific permissions
Some audit data restricted to administrators
Viewing audit trails is itself often logged
Troubleshooting
Issue: Can't see audit history

Solutions:

Check you have proper permissions
Look for different location (button vs. hover)
Try different section of member profile
Contact administrator if consistently unavailable
Issue: Audit history incomplete

Possible Reasons:

Data migrated from old system (pre-dates tracking)
Field wasn't tracked historically
System configuration change
Technical issue - report to IT
Issue: Can't export audit history

Solutions:

Check export permissions
Try smaller date range
Remove filters and try again
Use different browser
Contact IT support
