How Do I Create a Manual Contribution Register?

Category: Contributions and Buybacks Time: 15-20 minutes Difficulty: ⭐⭐⭐ Advanced

Before You Begin:

Have member information ready
Know contribution amounts and dates
Understand why manual entry is needed
Have authorization if required
Access to PensionPro+ with Contributions Center permissions
Posting numbers from your employer or plan
Member contribution data prepared and reconciled
Supporting documentation for all contributions
Unit information for contributions
Contribution rates and posting codes verified

Related Topics:

Upload Contributions

What This Does

Walks you through the process of creating and posting a manual contribution register in PensionPro+. This allows you to manually enter employee and employer contributions, verify totals match received amounts, and post them to member records. Perfect for contribution records that cannot be imported via file upload.

Allows you to manually enter contribution data one member at a time when file upload isn't available or practical. Used for corrections, one-off contributions, missed periods, or small batches.

When to Use Manual Entry
Use Manual Entry For:

✅ Single Member Corrections

Fix one member's incorrect contribution
Add missed contribution for one person
Adjust specific error

✅ Small Batches

1-10 members
Too few for file upload
Quick corrections needed

✅ Special Situations

Retroactive contributions
Corrections to posted data
Make-up payments
Buyback contributions
One-time adjustments

✅ Missing File Upload

Employer didn't provide file
File format issues can't be resolved quickly
Need immediate posting
Don't Use Manual Entry For:

❌ Large Batches

25+ members
Regular payroll processing
Standard employer files
Use Upload Contributions instead

❌ Recurring Entries

If same data repeats regularly
Better to create proper file upload process
Quick Steps
Click hamburger menu → Contributions Center
Fill posting details – Posting Number, Payroll Date, Period Start Date, Period End Date, Unit, and Template
Click +Add Row at the bottom to add member entries
Enter contribution details for each member (fields vary by template)
Review all entered data
Post contributions
Verify posted correctly
Step-by-Step Instructions
Step 1: Navigate to Contributions Center
Click hamburger menu (☰) → Contributions Center
Contributions Center page opens
Select Deduction Processing tab
Step 2: Enter Register Header Information

Complete these fields:

Posting Number (Required)

Enter a unique posting number/identifier for this register
Must be unique — the system will not accept duplicates
Used to track and reference this specific posting

Payroll Date (Required)

The payroll date associated with this posting
Format: MM/DD/YYYY

Period Start Date (Required)

The beginning date of the contribution period
Format: MM/DD/YYYY

Period End Date (Required)

The ending date of the contribution period
Format: MM/DD/YYYY
Must be on or after the Period Start Date

Unit (Required)

Select the organizational unit from the dropdown

Template (Required)

Select the template that defines the contribution fields for this register
Different templates will result in different required fields in the next step
Step 3: Add First Member

Click on newly created posting on the left side of the screen.

Search for Member:

Click the +Add Row button at the bottom of the screen to add a new member entry. Find the member using the search field and fill in all relevant fields. Once done, click Save.

Verify correct member:

Check Member ID
Verify name matches
Confirm correct person selected
Step 4: Enter Member Contribution Details

For the selected member, enter the required contribution fields.

The fields available in this step depend on the Template selected in Step 2. Different templates are configured differently for each board and will display different required and optional fields. Contact your administrator for guidance on which template to use and what fields are expected for your board's contribution entries.

Step 5: Save Member Entry
Review all entered amounts
Verify accuracy
Click Save or Add button
Member added to register
Appears in list of entries

Member entry shows:

Member name and ID
Earnings amount
Employee contribution
Employer contribution
Service credit (if entered)
Step 6: Add Additional Members (If Needed)

For multiple members:

Click +Add Row again
Search for next member
Enter their contribution details
Save entry
Repeat for each member

Running totals may display:

Total members: 5
Total earnings: $25,000.00
Total employee contributions: $1,250.00
Total employer contributions: $1,250.00
Step 7: Edit or Remove Entries (If Needed)

To Edit:

Click on member entry in list
Amounts become editable
Make corrections
Save changes

To Remove:

Find member in list
Click delete/remove icon (🗑️)
Confirm removal
Entry removed from register
Step 8: Review Complete Register

Before posting, verify:

Header Information:

Posting description is clear
Pay period dates are correct
Employer/unit is correct

Member Entries:

All intended members included
No duplicate entries
Amounts are correct
Earnings match source documents
Contributions calculated properly

Totals:

Total amount seems reasonable
Member count is correct
No obvious errors in totals
Step 9: Post the Manual Register

Ready to post:

Click Post or Submit button
Confirmation dialog appears
Shows summary of what will post
Review one final time
Click Confirm to proceed

⚠️ Important: Posting updates member accounts. Contact administrator if corrections are needed.

Posting process:

System processes each entry
Contributions added to member accounts
Service credit updated
Accumulated deductions updated
Usually completes quickly (seconds to minutes)
Step 10: Verify Posted Contributions

After posting:

Check Confirmation:

Success message appears
Posting number displayed (record this!)
Summary report available

Spot Check Members:

Open a few member profiles
Navigate to their contribution history
Verify manual entries appear
Check amounts match what you entered

Run Reports:

Generate posting report
Review member by member
Verify totals
Fields Explained
Earnings (Gross Pay)

What it is: Total compensation before deductions Used for: Calculating contributions, service credit, retirement benefits Example: $5,000.00 for bi-weekly period Tips: Must match payroll records, includes regular and overtime (unless separated)

Employee Contribution (Employee Deduction)

What it is: Amount deducted from employee's pay for pension Used for: Member's accumulated deductions, retirement account balance Typically: 5-12% of earnings (varies by system) Example: $250.00 (5% of $5,000) Tips: Check if pre-tax or post-tax matters for reporting

Employer Contribution (Employer Match)

What it is: Amount employer contributes on member's behalf Used for: Pension funding, may affect benefit calculations Typically: Equal to or greater than employee contribution Example: $250.00 (matching 5%) Tips: Some systems track separately, others combine

Service Credit

What it is: Pension time earned for this period Used for: Retirement eligibility, benefit calculations Typically: Prorated based on period length Example: 0.0385 (half month), 0.0833 (one month) Calculation: Days in period ÷ 365 = service credit Tips: May auto-calculate; verify if unusual period

Common Scenarios
Scenario 1: Single Member Correction

Situation: One member's contribution was under-deducted by $50

Steps:

Navigate to Contributions Center → Deduction Processing tab
Click Create Manual Register
New Posting Number: "CORR-2024-001"
Posting Date: Today's date
Click Create
Click on newly created posting in left panel
Click +Add Row at the bottom
Search and select member: John Smith
Fill all required fields per the template
Click Save
Review entry in register
Click Post Register
Verify in Smith's contribution history

Result: Correction posted, Smith's balance updated

⏱️ Time: 10 minutes

Scenario 2: Missed Pay Period for Small Group

Situation: 3 members missed in uploaded file

Steps:

Navigate to Contributions Center → Deduction Processing tab
Click Create Manual Register
New Posting Number: "MISSED-PP23"
Posting Date: Current date
Click Create
Click on newly created posting
For each of the 3 members:
Click +Add Row at the bottom
Search and select member
Fill all required fields per the template
Click Save
Review all 3 entries in register table
Verify totals are correct
Click Post Register

Result: 3 members now have contributions for missed period

⏱️ Time: 20 minutes

Scenario 3: Retroactive Contribution

Situation: Member should have been contributing 6 months ago

Steps:

Open Create Manual Register
Description: "Jones Retroactive - 6 months"
Pay Period: Original 6-month-ago dates
Create separate register for each pay period OR
Single register with accumulated amounts
Add Member: Jones
Enter accumulated earnings and contributions
Notes: "Retroactive for 6 months, approved by [supervisor]"
Post register
Verify service credit awarded

Result: Member's account updated with back contributions

⏱️ Time: 15 minutes

Scenario 4: Make-Up Payment Application

Situation: Member making lump-sum make-up payment

Steps:

Open Create Manual Register
Description: "Garcia Makeup Payment - Service 2018-2019"
Pay Period: Original service period
Add Member: Garcia
Earnings: Original earnings (from calculation)
Employee Contribution: Make-up amount paid
Notes: "Make-up payment received [date], check #12345"
Post register
Update member's makeup tracking

Result: Make-up payment applied, service credit awarded

⏱️ Time: 15 minutes

Best Practices

✅ DO:

Double-check all amounts before posting
Use clear, descriptive posting names
Include reference numbers in notes
Verify member before entering data
Keep source documents for reference
Post promptly (same day if possible)
Verify posted contributions immediately
Document reason for manual entry
Get approval if required
Use correct pay period dates

❌ DON'T:

Rush through entries (accuracy critical)
Use manual entry for large batches
Forget to record posting number
Post without reviewing
Enter contributions for wrong period
Duplicate existing contributions
Use vague posting descriptions
Skip verification step
Post without authorization (if required)
Delete entries without careful consideration

Common Questions

Q: When should I use manual entry vs. file upload? A: Use manual for 1-10 members or quick corrections. Use upload for 25+ members or regular processing.

Q: Can I post contributions for past periods? A: Yes. Enter the actual pay period dates from the past. System allows retroactive posting.

Q: What if I enter wrong amount? A: Before posting: edit the entry. After posting: contact administrator for correction assistance.

Q: Do manual entries look different than uploaded? A: No. Once posted, manual and uploaded contributions are identical in member records.

Q: Can I save partial register and finish later? A: Depends on system. Some allow saving draft, others require completing in one session. Check with administrator.

Q: How do I calculate service credit? A: Days in period ÷ 365 = years. Or system may auto-calculate based on pay period dates.

Q: What if member has multiple contribution rates? A: Enter one register per rate/type, or system may support multiple entries per member.

Q: Can I copy from previous period? A: Some systems offer copy feature. Otherwise, manual re-entry required.

Q: What happens if I post duplicate by mistake? A: System may catch it (validation error). If posted, contact administrator to correct the duplicate.

Q: How do I know what posting number was assigned? A: Displayed immediately after posting. Record it! Also appears in posting history.

Troubleshooting
Issue: Can't find member when searching

Solutions:

Try searching by different field (name vs. ID vs. SSN)
Check spelling
Verify member exists in system
Add member first if truly missing
Check if member is terminated (may need different flag)
Issue: System won't accept amount entered

Solutions:

Remove dollar signs and commas (enter numbers only)
Check for proper decimal format (250.00 not 250,00)
Verify not entering negative (unless specifically allowed)
Check field limits (may have max amount)
Try rounding to 2 decimal places
Issue: Can't post register (button disabled)

Solutions:

Verify all required fields completed
Check that at least one member added
Look for validation error messages
Ensure pay period dates are valid
Check if description is required
Verify you have posting permissions
Issue: Posted to wrong pay period

Solutions:

Contact administrator for correction assistance
Re-create manual register with correct dates
Post corrected version
Document the correction
Notify affected members if significant
Issue: Totals don't match expected

Solutions:

Review each member entry individually
Check for typos in amounts
Verify calculation method
Use calculator to verify math
Check if any members missing or duplicated
Issue: Member's account doesn't show contribution

Solutions:

Verify posting completed (check status)
Allow time for processing (refresh member page)
Check correct member was selected
Verify posting number in contribution history
Check filters on contribution history view
Contact administrator if truly missing
