How Do I Generate and View Reports Through Reports Center?

Category: Reports and Analytics Time: 5-25 minutes Difficulty: ⭐⭐ Intermediate

Before You Begin:

User account with access to Reports Center
Know which report category you need
Report criteria ready (dates, member info, filters)
Understanding of desired output format

Related Topics:

View Generated Reports
Create Customized Report
Run Ad-Hoc Queries
What This Does

Walks you through the process of generating, viewing, and retrieving reports through the Reports Center. The Reports Center is your central hub for generating, viewing, and managing all system reports. Reports Center provides access to hundreds of pre-built reports across multiple categories (Accounting, Retiree Payroll, Refunds, etc.) with customizable criteria and multiple output formats.

Use it to create standard reports, access previously generated reports, and export data in various formats (PDF, Excel, CSV). The Reports Center organizes reports by category and allows you to search, filter, and download reports quickly.

Reports Center is Your Centralized Reporting Hub:

Think of it as a library of pre-built reports organized by category. You select a report, provide criteria, and the system generates formatted output ready to download, print, or share.

Quick Steps
Click hamburger menu (☰) → Reports Center
Browse by category or search for a specific report
Click on a report to open the generator
Fill in required parameters and options
Click Generate Report
View or download the generated report
Step-by-Step Instructions
Step 1: Access Reports Center

Where to Go:

Click hamburger menu (☰) in top-left
Click Reports Center (signal bars icon)
The Reports Center opens with two tabs:
Reports tab (for generating new reports)
Reports Archive tab (for viewing previously generated reports)

The Reports tab displays by default.

Step 2: Browse Available Reports

What You'll See:

The Reports page has two main sections:

Left Sidebar: Report Categories (organized by function)
Right Panel: Reports within the selected category

Report Categories Include:

Member Reports - Individual member information
Financial Reports - Contributions, balances, transactions
Payment Reports - Payroll, checks, direct deposits
Accounting Reports - Ledgers, reconciliations
Year-End Reports - Annual statements, tax forms
Compliance Reports - PERAC, regulatory submissions

To Browse:

Click a category on the left side
The right panel updates to show available reports
Each report shows:
Report Name - Clear description
Report Description - Brief explanation of what the report includes

💡 Tip: The category count shows how many reports are available in each category.

Step 3: Search for a Report

Using the Search Box:

Locate the search box at the top of the Reports page
Type part of the report name or description
Results filter automatically as you type
Click a report from the search results

Search Tips:

Search works across report names and descriptions
Partial matches work (e.g., "payroll" finds all payroll-related reports)
Press Escape or click the X button to clear search
Step 4: Generate a Report

Selecting a Report:

Click on a report name from the category list or search results
The report generation form opens

Filling Out Report Parameters:

Reports typically include these types of fields:

Date Fields:

As Of Date - Report data up to this date
Start Date / End Date - Date range for the report
Use the calendar icon to select dates

Member Selection:

Specific Member - Search and select by name or ID
All Members - Leave blank for system-wide reports

Employer/Group Selection:

Employer - Select specific employer group
All Employers - Leave blank for all groups

Format Options:

PDF - Formatted, print-ready document
Excel (XLSX) - Spreadsheet with editable data
CSV - Raw data export for external systems
Word (DOCX) - Editable document format (some reports)

💡 Tip: Required fields are marked with an asterisk (*).

Step 5: Generate the Report

To Run the Report:

Review all entered parameters
Select desired output format (PDF, Excel, CSV, etc.)
Click the blue Generate Report button
A progress indicator appears
The report generates and opens automatically

What Happens:

✅ System validates your parameters
⏳ Report generates (may take a few seconds to minutes depending on size)
📄 Report opens in a viewer or downloads to your computer
💾 Report is automatically saved to the Reports Archive
Step 6: View the Generated Report

Report Generation Process:

When you click Generate Report, the system initiates a batch job to process the report:

Batch Job Starts: The report generation begins in the background
Wait for Completion: Processing time varies depending on report size and complexity
Notification: A notification will appear once the report generation is complete
Access the Report: Navigate to Reports Center → Reports Archive tab

Finding Your Generated Report:

Go to Reports Center → Reports Archive tab
Search for the report using:
Report Name: The title of your report
Report Category: The category classification
Created On: Date and time generated
Created By: Your username
Status: Should show "Completed"
Download: Click format icon to download

💡 Tip: Use the date filter to narrow down to recently generated reports.

Step 7: Access Previously Generated Reports

Using the Reports Archive Tab:

Click the Reports Archive tab at the top
All previously generated reports appear in a table

Reports Archive Columns:

Report Name - The report title
Report Category - Category classification
Created On - When the report was generated
Created By - Who generated the report
Status - Completed, Processing, or Failed
Download - Quick download buttons for available formats
Step 8: Filter and Search the Archive

Using Filters:

The Reports Archive includes powerful filtering:

Report Name Filter:

Type in the Report Name field
Results filter as you type

Report Category Filter:

Select from Report Category dropdown
Shows reports from that category only

Date Range Filter:

Click Created On Between date fields
Select start and end dates
Shows reports generated in that timeframe

My Reports Only Checkbox:

Check Show My Reports Only
Filters to reports you personally generated

Refresh Button:

Click Refresh to reload the archive
Updates with any newly completed reports
Step 9: Download from Archive

To Download a Previously Generated Report:

Find the report in the Reports Archive table
Look in the Download column
Click the format icon you want:
PDF icon - Download PDF
Excel icon - Download XLSX
CSV icon - Download CSV file
File downloads to your browser's download folder

Opening Downloaded Reports:

PDF files open in Adobe Reader or browser
Excel files open in Microsoft Excel or compatible program
CSV files open in Excel, Google Sheets, or text editor
Common Report Scenarios
Scenario: Generate a Member Statement

Steps:

Go to Reports Center → Reports tab
Select Member Reports category
Click Member Account Statement
Search for and select the member
Choose As Of Date
Select PDF format
Click Generate Report
Report opens showing member's account history
Scenario: Export Payroll Data to Excel

Steps:

Go to Reports Center → Reports tab
Select Payment Reports category
Click Payroll Register
Enter Start Date and End Date
Select XLSX format
Click Generate Report
Excel file downloads with payroll data
Open in Excel for analysis or editing
Scenario: Find and Reprint a Previous Report

Steps:

Go to Reports Center → Reports Archive tab
Enter report name in Report Name filter
Select date range when it was generated
Find the report in the results table
Click the PDF icon in the Download column
Report downloads again (same data as original)
Best Practices

✅ DO:

Choose the appropriate format for your needs (PDF for printing, Excel for analysis)
Use date filters in the archive to find recent reports quickly
Check "My Reports Only" to see your personal report history
Download important reports to save locally
Review report parameters before generating to avoid errors

❌ DON'T:

Generate the same report repeatedly - check the archive first
Select date ranges that are too large (may cause timeouts)
Close the browser while reports are generating
Forget to specify required parameters
Common Questions

Q: How long does it take to generate a report? A: Most reports generate in 5-30 seconds. Large reports with extensive data (e.g., all members for an entire year) may take 1-3 minutes.

Q: Where do downloaded reports go? A: Reports download to your browser's default download folder (usually "Downloads"). Check your browser's download bar or settings.

Q: Can I schedule reports to run automatically? A: Currently, reports must be generated manually. Contact your system administrator about scheduled reporting needs.

Q: How long are reports kept in the archive? A: Reports are retained according to your system's retention policy (typically 90 days to 1 year). Check with your administrator.

Q: Can I share a report with someone else? A: Yes, download the report and email it, or tell the recipient to look in the Reports Archive (they'll need appropriate permissions).

Q: What's the difference between PDF and Excel formats? A: PDF is formatted for viewing/printing and cannot be edited. Excel allows you to sort, filter, and manipulate the data.

Q: Why don't I see all report categories? A: You only see categories containing reports you have permission to generate. Contact your administrator for additional access.

Q: Can I generate a report for a custom date range? A: Yes, most reports allow you to specify start and end dates for custom periods.

Q: What does "Status: Processing" mean in the archive? A: The report is still being generated. Click Refresh after a few moments to check if it's completed.

Troubleshooting
Issue: Report generation fails or times out

Solutions:

Check that all required fields are filled in correctly
Try a smaller date range
Verify you have permission to generate this report type
Wait a moment and try again (system may be busy)
Contact your system administrator if persistent
Issue: Downloaded file won't open

Solutions:

Ensure you have appropriate software installed (Adobe Reader for PDF, Excel for XLSX)
Check that download completed fully (file size should be reasonable)
Try downloading in a different format
Try a different browser
Check for browser download blocking or security settings
Issue: Can't find a report in the archive

Solutions:

Click Refresh to update the list
Check date range filters - expand to wider range
Uncheck "Show My Reports Only" if someone else generated it
Clear all filters to see everything
Verify the report completed successfully when generated
Issue: Report is blank or shows no data

Solutions:

Verify the date range includes data
Check if filters exclude all records (e.g., specific employer with no members)
Confirm data exists for the selected parameters
Try generating with broader criteria
Contact your administrator if data should be present
