How Do I View Generated Reports?

Category: Reports and Analytics Time: 5-10 minutes Difficulty: ⭐ Beginner

Before You Begin:

You have access to the system (logged in)
You know which report type you're looking for (system-wide or member-specific)
You understand the difference between Reports Archive and member reports

Related Topics:

Generate and View Reports Through Reports Center
Download Reports
What This Does

Explains how to access and view reports generated within the system across three primary locations: the Reports Center for system-wide reports, individual member profiles for member-specific reports, and the Payment Center for retiree payroll-related reports. All reports can be filtered, downloaded, and managed through intuitive interfaces.

The Reports Archive allows you to access all previously generated reports. Whether you need to reprint a report from last week or download data from last month, the Reports Archive stores all your generated reports with powerful search and filter tools to help you find exactly what you need.

💡 Note: This guide focuses specifically on viewing and accessing reports in the Reports Archive. For information on generating new reports, see
Generate and View Reports Through Reports Center
.

Three Main Locations to View Reports:

Reports Center (System-Wide)

Access all generated reports across the entire system with global filtering and search capabilities.

Member Profile (Member-Specific)

View reports generated specifically for an individual member with member context.

Payment Center (Payroll-Specific)

Access retiree payroll-related reports and processing documentation.

Quick Steps

For System-Wide Reports:

Click hamburger menu (☰) → Reports Center
Click the Reports Archive tab
Use filters to find your report (Report Name, Category, date ranges)
Click format icon to download
Report downloads to your computer

For Member-Specific Reports:

Open member profile
Select Reports tab
View reports generated for that member
Click download icon for desired format

For Payroll Reports:

Navigate to Payment Center
Select Reports card
View payroll-related reports
Download as needed
Step-by-Step Instructions
Step 1: Access the Reports Archive

Where to Go:

Click hamburger menu (☰) → Reports Center
The Reports Center opens
Click the Reports Archive tab at the top
The archive table displays all generated reports

What You'll See:

A table showing all previously generated reports with columns:

Report Name - The name/title of the report
Report Category - Category classification (Member, Financial, etc.)
Created On - Date and time the report was generated
Created By - Username of who generated the report
Status - Current status (Completed, Processing, Failed)
Download - Quick download buttons for available formats
Step 2: Understanding Report Status

Report Status Indicators:

Completed:

✅ Report successfully generated
All download formats available
Ready to view or download

Processing:

⏳ Report is currently being generated
Download buttons not yet available
Click Refresh to check for completion

Failed:

❌ Report generation encountered an error
No download buttons available
May need to regenerate with different parameters

💡 Tip: The archive auto-refreshes when reports are processing. Watch for the "Auto-refreshing..." indicator.

Step 3: Filter by Report Name

Using the Report Name Filter:

Locate the Report Name filter box at the top
Type part of the report name
Example: Type "payroll" to find all payroll reports
Results filter automatically as you type
Table updates to show only matching reports

Search Tips:

Partial matches work (no need to type the full name)
Search is case-insensitive
Clear the field to show all reports again
Step 4: Filter by Report Category

Using the Category Filter:

Click the Report Category dropdown
Select a category:
All Categories (default - shows everything)
Member Reports
Financial Reports
Payment Reports
Accounting Reports
Year-End Reports
Compliance Reports
Table updates to show only reports from that category

💡 Tip: Combine category filter with name search for precise results.

Step 5: Filter by Date Range

Using the Date Range Filter:

Locate the Created On Between date fields
Click the first date field for start date
Select start date from calendar
Click the second date field for end date
Select end date from calendar
Click outside the calendar or press Enter
Table updates to show only reports created in that range

Common Date Ranges:

Last Week: Set to 7 days ago through today
Last Month: Set to first and last day of previous month
This Quarter: Set to first day of quarter through today
Specific Period: Set any custom date range

💡 Tip: Clear date fields by clicking the X icon in the date input.

Step 6: Filter to Your Reports Only

Show My Reports Only:

Find the Show My Reports Only checkbox
Check the box
Table filters to reports you personally generated
Uncheck to see all users' reports again

When to Use:

Finding reports you recently created
Reviewing your personal report history
Checking if you already ran a specific report
Step 7: Refresh the Archive

Manual Refresh:

Click the Refresh button (top-right of filters)
Archive reloads with latest data
New reports appear
Status updates for processing reports

Auto-Refresh:

When reports are processing, auto-refresh activates
"Auto-refreshing..." indicator appears
Archive updates every 5 seconds automatically
Stops when all reports complete

💡 Tip: Use refresh after generating a report to see it appear in the archive.

Step 8: View a Report

Opening the Report Viewer:

Find the report in the table
Click anywhere on the report row (except download buttons)
The Report Details viewer opens in a modal

What You'll See:

For PDF Reports:

PDF document viewer displays the report
Scroll through pages in the viewer
Zoom in/out using browser controls

For Data Reports (Excel/CSV):

Data table shows the report contents
Columns display all data fields
Pagination for large datasets
Search box to filter visible data

Download Options:

Format buttons at the top
Download the same report in different formats
Click button to download immediately
Step 9: Download a Report

Quick Download from Archive Table:

Find your report in the table
Look in the Download column
Click the format icon you want:

Download Format Icons:

PDF icon (fa-file-pdf) - Adobe PDF document
Excel icon (fa-file-excel) - XLSX spreadsheet file
CSV icon (fa-file-csv) - Comma-separated values file
Word icon (fa-file-word) - DOCX document (some reports)
File downloads to your browser's download folder

File Name Format:

Files download with descriptive names
Usually includes report name and date
Example: "Payroll_Register_2025-01-15.xlsx"
Step 10: Clear Filters

Resetting the Archive View:

Clear individual filters:

Clear text from Report Name field
Select "All Categories" from Category dropdown
Clear dates from date range fields
Uncheck "My Reports Only"

Or click Clear Filters button (if available)

Table resets to show all reports

💡 Tip: Start with broad filters and narrow down as needed.

Common Viewing Scenarios
Scenario: Find Yesterday's Payroll Report

Steps:

Go to Reports Archive tab
Type "payroll" in Report Name filter
Set Created On Between to yesterday's date (both fields)
Find the report in results
Click PDF icon to download
Scenario: View All Reports from Last Month

Steps:

Go to Reports Archive tab
Set Created On Between:
Start: First day of last month
End: Last day of last month
Review all reports generated in that period
Download any needed reports
Scenario: Check if You Already Ran a Report

Steps:

Go to Reports Archive tab
Check "Show My Reports Only"
Type report name in search
If found, download existing report
If not found, generate new report
Sorting the Archive

Click Column Headers to Sort:

Report Name - Alphabetical order
Created On - Chronological order (default: newest first)
Created By - Alphabetical by username
Status - Grouped by status type

Sort Direction:

Click once: Ascending (A-Z, oldest-newest)
Click again: Descending (Z-A, newest-oldest)
Arrow icon shows current sort direction

💡 Tip: Default sort is Created On descending (newest reports first).

Pagination

Navigating Large Lists:

If you have many reports:

Page numbers appear at the bottom
Items per page dropdown (25, 50, 100, 250 records)
First/Previous/Next/Last buttons for navigation

To Change Page Size:

Click the items per page dropdown (bottom-left)
Select larger number (e.g., 100)
More reports display on each page
Best Practices

✅ DO:

Use filters to narrow results before scrolling
Check My Reports Only to find your own reports quickly
Use date ranges to limit to relevant timeframes
Refresh after generating new reports
Download reports you'll need offline

❌ DON'T:

Leave too many filters active (may hide reports you need)
Forget reports may still be processing (check status)
Assume old reports are automatically deleted (check retention policy)
Download the same report repeatedly (save it locally)
Common Questions

Q: How long are reports kept in the archive? A: Retention varies by system configuration (typically 90 days to 1 year). Contact your administrator for your system's policy.

Q: Can I delete reports from the archive? A: Typically, users cannot delete archive reports. Contact your administrator if specific reports need removal.

Q: Why don't I see a report I just generated? A: Click Refresh to update the list. Also check that filters aren't hiding it.

Q: Can I see reports generated by other users? A: Yes, uncheck "Show My Reports Only" to see all reports (permissions permitting).

Q: What does "N/A" in the Download column mean? A: The report is still processing or failed to generate. Check the Status column.

Q: Can I re-run a report from the archive? A: No, the archive is view-only. To regenerate, go to the Reports tab and generate a new copy.

Q: Why are some format icons missing? A: Not all reports support all formats. Only available formats show download icons.

Q: Can I export the archive list itself? A: The archive is for viewing individual reports. Use the filter and sort features to find specific reports.

Q: What if a report shows "Failed" status? A: The generation encountered an error. Try regenerating with adjusted parameters or contact support.

Troubleshooting
Issue: Can't find a specific report

Solutions:

Clear all filters first
Check date range includes when report was generated
Uncheck "My Reports Only" if someone else generated it
Verify the report completed successfully (check Status)
Click Refresh to reload the list
Issue: Download buttons don't appear

Solutions:

Check Status column - must be "Completed"
Wait if status is "Processing" - click Refresh
Regenerate if status is "Failed"
Verify you have download permissions
Try a different browser if buttons don't load
Issue: Downloaded file is corrupted or won't open

Solutions:

Try downloading again
Try a different format (PDF instead of Excel)
Check your download folder for correct file
Verify download completed (check file size)
Try a different browser
Contact support if problem persists
Issue: Archive shows no reports

Solutions:

Clear all active filters
Expand date range or remove date filter
Uncheck "My Reports Only"
Verify reports have been generated previously
Click Refresh to reload
Check permissions with administrator
