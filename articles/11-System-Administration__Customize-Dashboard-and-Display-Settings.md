How Do I Customize My Dashboard and Display Settings?

Category: System Administration Time: 5-10 minutes Difficulty: ⭐ Beginner

Before You Begin:

You must be logged into PensionPro+
You have access to your user profile settings
You understand your typical workflow and frequently used modules

Learn how to personalize your dashboard by configuring widgets, adjusting display order, and managing your workspace preferences. Customizes your PensionPro+ dashboard and display environment to match your personal preferences and workflow. This includes switching between Light and Dark display modes, rearranging Quick Launch menu items to prioritize your most-used features, and managing the Recent News content that appears on your homepage.

Overview

The PensionPro dashboard is fully customizable, allowing each user to control which widgets appear, their display order, and how information is presented. Customize your dashboard to show the most relevant information for your daily work.

User Preference: Each user's dashboard settings are saved independently

Access Dashboard Customization
From Dashboard
Navigate to the Dashboard from the main menu
Click the Settings icon (gear) in the dashboard header
Or click Customize Dashboard button
The Dashboard Edit modal opens
Available Widgets

The system includes these dashboard widgets:

Widget	Description	Icon
Quick Launch	Quick access to frequently used features	🚀 Rocket
Recent News	Latest news and announcements	📰 Newspaper
Batch Queue	Background job processing status	✓ List
Recently Viewed	Recently accessed member records	🕐 Clock
Member Status Breakdown	Summary of member statuses	📊 Chart
Payroll Process	Current payroll processing status	💵 Money
Retirement Processes	Active retirement calculations	⏱️ User Clock
My Memos	Memos assigned to you	📝 Note
Customize Widget Display
Step 1: Open Settings
Click the Settings icon on the dashboard
The Dashboard Edit modal displays all available widgets
Step 2: Enable/Disable Widgets

To Show a Widget:

Find the widget in the list
Toggle the switch to ON (blue)
Widget details expand when enabled

To Hide a Widget:

Find the widget in the list
Toggle the switch to OFF (gray)
Widget collapses in the list

Widget Counter:

Top of modal shows: "X of Y widgets enabled"
Helps track how many widgets are active
Step 3: Reorder Widgets

Change Display Order:

Widgets display in the order shown in settings
Drag-and-drop is supported (future enhancement)
Order determines left-to-right, top-to-bottom placement

Note: The Quick Launch widget typically remains in the first position and may not be reorderable.

Step 4: Save Settings
Review your widget selections and order
Click Save button (bottom right)
Dashboard refreshes with new layout
Success message: "Dashboard settings saved successfully"
Step 5: Cancel Changes

To discard changes:

Click Cancel button
Or click X to close modal
Dashboard returns to previous state
Reset to Default Settings
Restore Original Layout
Open Dashboard Settings
Click Reset to Defaults button
Info message: "Settings reset to defaults. Click Save to apply."
Click Save to confirm
Dashboard returns to system default configuration

Default Configuration:

All widgets enabled
Standard display order
System-defined layout

Troubleshooting
Widgets Not Saving

If dashboard changes don't save:

Check browser console for errors
Ensure you clicked Save button
Verify network connection
Try clearing browser cache
Re-login and try again
Widget Not Displaying

If enabled widget doesn't appear:

Verify widget is toggled ON in settings
Check that you have permission to view widget
Verify data source is available
Refresh dashboard
Try resetting to defaults
Slow Dashboard Loading

If dashboard is slow:

Disable unused widgets
Clear browser cache
Check network connection
Reduce number of enabled widgets
Contact administrator about system performance
Layout Issues

If widgets display incorrectly:

Zoom browser to 100% (Ctrl+0)
Resize browser window
Clear browser cache
Try different browser
Check screen resolution settings
Best Practices

✅ Do:

Enable only widgets you use regularly
Organize widgets by priority/frequency
Review and update settings periodically
Use Quick Launch for common tasks
Check Batch Queue before leaving for the day
Star frequently accessed members in Recently Viewed

❌ Don't:

Enable all widgets if you don't need them
Ignore batch queue errors or warnings
Forget to customize for your role
Leave irrelevant widgets enabled
Overcrowd dashboard with too many widgets

Each user's dashboard is independent and doesn't affect other users

Quick Launch items can be customized (implementation dependent)
Widget display order defaults to system-defined priority
Dashboard supports both light and dark themes (if enabled)
Some widgets may require specific permissions to display data
Dashboard performance improves with fewer enabled widgets
